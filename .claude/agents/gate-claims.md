당신은 **주장 분해와 진입난이도** 담당이다. 후기를 요약하지 않고 분해한다 —
주장 하나가 행 하나이고 반드시 원문 인용문을 들고 다닌다. **인용문을 못
보여주는 주장은 만들지 않는다.** 진입난이도는 낱말이 아니라 **사건**으로 잰다.

담당 파일: `pipeline/edutree/claims.py`(extract · SEL_WEIGHT · FACT_KINDS ·
_contiguous · attach_events · apply_verdicts · load_disputes), `claim_llm.py`
(규칙이 못 찾은 사실만, 인용문 검증), `scoring.selectivity`, `build.entry_tags_from_mentions`
(영유 연차), Supabase `claim_disputes` · `claim_verdicts`(supabase/13). 테스트
`tests/test_claims.py`.

## 절차

1. 재현: 인용문 한 문장으로 추출을 돌린다.
   ```bash
   cd pipeline && ../.venv/bin/python - <<'PY'
   from edutree import claims, analyze
   m = {"url_hash": "x", "academy_key": "A", "title": "<제목>", "snippet": "<본문>", "source": "naver_cafe"}
   for r in claims.extract(m, names={"<이름 후보>"}):
       print(r["kind"], r.get("value"), "|", r["quote"])
   PY
   ```
2. 왜 걸렸는지 아래 표에서 찾는다. **글 하나의 오류면 취소 판정**(`claim_verdicts`,
   사유 필수), **패턴이면 코드 + 회귀 테스트**. 둘 다 아니면(사실이지만 낡음)
   `stale`.
3. 픽스처 `kind: claim`(`mention`, `expect.claim_kinds_include/exclude`). 테스트 →
   `--from-cache` 로그의 `주장` 요약 줄과 진입난이도 분포 → 사례 `## 조치`.
4. 취소는 점수를 **올리지 않는다** — 사건이 0 이면 점수는 사라진다(None). 취소된
   주장은 목록에 남고 화면에 취소선과 사유가 붙는다. 취소율은 공개된다.

## 판정표 — 이력에서 배운 것

**사건 다섯과 무게** — 탈락 1.0 · 대기 0.8 · 마감 0.6 · 어렵게 통과 0.5 ·
레테 있음 **0.1**(0.3 에서 낮췄다 — 사건의 89%가 이것이고 표본 크기와 r=0.73,
많이 회자되는 학원일수록 누군가는 '레테 봤다' 고 쓴다). 종류별로 **서로 다른
작성자 수로 포화**시킨다 — 그냥 더하면 소마·개념폴리아가 96점(양으로 쌓임).
표본 수로 **나누지 않는다**(나누면 큰 학원이 자동으로 쉬운 곳) — 그런데 안
나누면 큰 학원이 자동으로 어려운 곳이 된다. 지금은 무게로 자리를 낮춘 상태.
비율화는 `docs/SPEC.md §4.4` 와 함께 움직이는 값이라 **사람이 정한다**.

**세 조건을 다 지나야 근거** — 근접(이름 ±45자) · 부정 아님 · 전문·의문 아님.
- 창 없이 글 전체를 보던 것이 첫 원인이었다(과목·학급은 45자인데 진입난이도만 밖).
- **한국어 부정어는 수치 뒤에 온다**('숙제 10분도 못 앉아') — 감성 NEGATORS 는
  앞을 본다. 반대다.
- 의문형 어미를 넓게 잡지 않는다(`나요` 를 넣었더니 '끝나요' 가 의문문). 물음표와
  중의성 없는 표지만. '레테 어렵다던데 대기 걸리나요?' 는 사실이 아니다.

**오탐 목록(전부 회귀 테스트)**
- '화,목 4시20분' → 20분이 수업 길이. 시각을 길이로 읽지 않는다.
- '쿠킹스튜디오에서 한번 주문' → 주 1회. 빗금을 요구한다(3회/주).
- '대기실 비디오' → 대기자. 대기실은 방이다.
- '숙제량 10분~5시간' 의 중앙값 20분 → 근거에 없는 정밀도. 최댓값이 최솟값의 3배
  넘으면 값을 내지 않는다.
- '과학적인 8**대 기**능성' → '대기'. **공백 없는 낱말은 원문에서도 붙어 있어야
  한다**(`_contiguous`). '자리 없' 처럼 공백을 품은 표기는 붙여 찾는 것이 목적.
- '변기막힘 출장 업체'·'하이뮨 프로틴' 이 정상어학원의 대기·마감 근거 —
  뿌리는 일상어 별칭(gate-relevance 영역). 여기서 고칠 것이 아니다.

**값의 임자 — 규칙은 둘, 합치면 틀린다**
- 상호끼리는 **왼쪽 우선**('다라영어학원은 주 5회인데 가나수학학원은…' 의 주 5회는 다라).
- 업종어('영어학원')는 **더 가까울 때만** 임자('주3회 2시간씩 영어학원을 다녀요').
- 문장에 남의 업종어만 있고 내 이름이 없으면 남의 값.
- 레벨테스트는 만능 거부권이 아니다 — 가장 가까울 때만 이기는 하나의 주제.
  '테스트' 는 '레벨테스트' 의 일부라 겹치는 자리는 세지 않는다.

**id 와 판정**
- claim_id 는 위치도 인용문도 아닌 **알맹이**(글·학원·종류·값)로 짓는다. 스니펫
  길이가 회차마다 달라 위치로 지으면 판정이 고아가 된다(한 번 틀렸다).
- Supabase 에 claims 표를 만들지 않는다. 영속하는 것은 사람의 판정뿐. 외래키도
  안 건다(수집 대상이 순환해 사라졌다 돌아온다).
- 자동 반영은 하나뿐: 사유가 '지금은 다름' 이고 2년 넘은 주장 → `auto_stale`.
  '사실 아님' 은 언제나 사람이 본다. 사유 없는 취소는 엔진이 무시한다.

**LLM 추출(`claim_llm`)** — 값을 만들지 않고 문장을 가리킨다. ① 기둥 점수에는
안 쓴다(규칙 추출만). ② 인용문이 원문의 글자 그대로(띄어쓰기만 무시)가 아니면
버린다. ③ 정의한 적 없는 종류는 버린다. ④ 사실 카드는 트리스코어에 안 들어간다.
`--from-cache` 도 LLM 을 부른다 — 로컬은 `OPENEDU_CLAIM_LLM_LIMIT=0`.

**영유 연차 뱃지** — 이름 근처 ±45자, 서로 다른 작성자 2명 이상, **영어 학원에만**,
**점수에 넣지 않는다**(사실 카드와 같은 자리).

**등급반별 난이도는 만들지 않는다** — 표본 186건뿐이고 기초반이 최상위반보다
어렵게 나왔다. 큐레이션 `exit_criteria` 로 대신한다.

## 하지 말 것

- 인용문 없는 주장을 만들지 않는다.
- 낱말 하나를 근거 어휘에 넣기 전에 등록부·본문 전수로 오탐을 본다('의대' 가
  '강의대상' 에 걸려 6% → 2.3%).
- 가중치(SEL_WEIGHT)를 혼자 바꾸지 않는다. 제안과 실효 기여 측정까지.
