당신은 **지점 게이트**(브랜드 이름으로 쓰인 후기를 어느 지점에 붙일 것인가)
담당이다. 유명 학원은 전국에 지점이 있고 수집은 학원 단위인데 후기는 브랜드
이름으로 쓰인다. 그대로 두면 분당 후기가 대치 점수가 된다(실측 에이프릴 377건
중 60건).

담당 파일: `pipeline/edutree/branches.py`, `analyze.REGION_WORDS` ·
`foreign_dong` · `region_hints`, `pipeline/data/regions.yaml`(dong_list),
`pipeline/data/seed_academies.yaml`(brand·aliases), 위키 `locality:`.
회귀 테스트 `tests/test_gates.py` 의 지점 절, `test_place_names.py`.

## 절차

1. **어느 규칙에 걸려야 했는지 정한다.** 제목을 먼저 본다(본문의 지역명은 대개
   남의 상호다). 재현:
   ```bash
   cd pipeline && ../.venv/bin/python - <<'PY'
   from edutree import analyze, branches
   print(analyze.region_hints("<제목>"))          # (권역 집합, 권역 밖 여부)
   print(analyze.foreign_dong("<제목>", ours={"대치동","도곡동"}, mine=()))
   PY
   ```
2. **형제 지점을 확인한다.** `branches.sibling_key(a)` 가 형제마다 같은가.
   `brand` 가 비어 `token:` 으로 갈리면 동네 말 규칙이 **아예 안 돈다**(시매쓰
   대치점이 그랬다). 시드 `aliases` 에 등록명을 넣어 잇는다.
3. 조치 층: 시드 brand/alias(형제 키) → 위키 `locality`(변별어) → `regions.yaml`
   dong_list → 코드(`OTHER_REGION_WORDS` · `BROAD_WORDS` · 규칙 순서) + 테스트.
   판정이 필요한 것은 `exclude_region` 규칙(질문 큐 경로) — 직접 넣지 않는다.
4. 픽스처 `tests/cases/<id>.yaml` (`kind: branch`, `academies` 둘 이상,
   `expect.kept_for`). 5·6 은 gate-relevance 와 같다(테스트 → `--from-cache` →
   사례 `## 조치` → `status: fixed`).

## 판정표 — 이력에서 배운 것

- **지역을 밝힌 글 → 그 권역 지점만.** 우리 4권역 밖(분당·평촌·송도…)이면
  어디에도 안 붙인다. 밝힌 권역이 제 권역이면 그쪽으로 **재귀속**(`rehomed`).
- **지역을 안 밝힌 글 → 형제 지점이 있으면 근거로 쓰지 않는다**(2026-09-05).
  전에는 걸리는 지점 전부에 '브랜드 공통' 으로 붙였는데, 지점별 순위에서
  어느 지점인지 모르는 글을 나눠 주면 그 등수를 설명할 수 없다(시매쓰 네
  지점이 같은 글로 2·3·4위). 지점이 하나뿐이면 불명일 것이 없으니 그대로 근거.
  '브랜드 공통' 딱지는 형제가 실제로 있을 때만 — 하나뿐인 학원에 붙이면 거짓.
- **제목이 우선.** 두 번 틀렸다. ① 제목+본문 합쳐 봤더니 '세종 엄마표영어' 가
  본문의 '대치M수학' 때문에 대치 근거. ② 제목에 우리 권역 말이 함께 있으면
  살렸더니 '[송도 논술 학원] 대치메이드학원 송도점' 이 통과 — **브랜드에
  박힌 '대치'**. 제목에 권역 밖 지역이 있으면 우리 말이 함께 있어도 버린다.
- **이름에 박힌 지역명은 지역이 아니다.** '러셀목동'·'글로벌에듀둔촌오륜'·
  '대치청담어학'. 이 가드가 없으면 청담어학(표본 387)의 근거가 통째로 날아간다.
- **목록에 없는 동 → 남의 동네**(`foreign_dong`). `OTHER_REGION_WORDS` 는 사람이
  채우므로 끝이 없다 → 우리 학군의 동이 아니면 남의 동네로 **뒤집어** 본다.
  9/3 실측 48건 전부 진짜 타지역(정자동·북가좌동·양평동·읍내동·중앙동·비전동).
  **두 글자는 보지 않는다**('운동·활동·아동·행동·이동·자동'). 앞뒤가 경계여야
  한다('동아리활동').
- **`OTHER_REGION_WORDS` 에 지역어를 넣기 전에 그 이름의 브랜드가 있는지 본다.**
  '종로' 를 넣으면 종로학원이 전부 타지역 글이 된다.
- **같은 학군 안 형제 지점은 권역 게이트로 못 가른다.** 시매쓰 반포점·방배점은
  둘 다 반포 학군. 형제만 가진 **동네 말**이 제목에 있으면 내 글이 아니다
  (`locality_words` + 위키 `locality`). 비대칭이 정상(방배점엔 변별어가 없다).
- **구(區) 이름은 변별어가 못 된다**(`BROAD_WORDS`: 강남·서초·송파·양천).
  '서초 시매쓰' 를 방배점 것으로 치면 반포점 근거 135 → 62. NEIS 법정동에서
  뽑을 때도 같은 필터(방배점 등록 동이 '서초동' 이라 한 번 놓쳤다).
- **'강남' 은 지역어가 아니지만 '강남점·강남본점·강남역' 은 지점이다.**
- `exclude_region` 규칙은 **제목만** 본다. 본문까지 보면 멀쩡한 근거가 날아간다 —
  같은 함정에 `branches.py` 에서 두 번 빠졌다. 사유가 '다른 지역 지점' 이면
  제목에 실제로 나온 지역어만 초안으로 채운다(목록 전체를 채우면 사람이 안 읽는다).
- 지점 묶음 키는 `brand` → 없으면 `dedupe.brand_token`. 같은 권역 안 여러 관은
  dedupe 가 이미 묶었으므로 **권역이 다른 것만** 잇는다.

## 하지 말 것

- 본문의 지역명으로 판정하지 않는다.
- 형제가 아닌 것을 형제로 만들지 않는다 — '최상위수학' 세 곳이 문제집 후기
  6건을 원문까지 공유한 통로가 이것이었다.
- 확률(%)로 지점을 배분하지 않는다. 모르면 안 붙인다.
