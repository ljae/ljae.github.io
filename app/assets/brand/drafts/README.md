# 로고 시안 — A안 「판면 + 경로」 (2026-08-29)

실록 판면의 세로 괘선(계선) 다섯 줄 중 하나가 계단처럼 올라간다.
**기록(계선)과 테크트리(경로)를 한 그림**으로 둔 것이 이 안의 전부다.
주묵은 도착점 하나에만 찍는다 — 도장을 브랜딩에 쓰지 않기 위해서다
(`theme.dart`: "도장은 단정할 수 있는 것에만 찍는다").

생성: Gemini 3 Pro Image (nano-banana-pro), 1K 드래프트.
**시안까지다.** 최종은 SVG 로 다시 그린다 — 획 두께가 `AppRule` 토큰
(0.7/1.0/2.0/3.0)인 디자인에서 래스터는 규칙을 지킬 수 없다.

## 넉 장

| 파일 | 구성 | 판정 |
|---|---|---|
| `a1-canon.png` | 계선 5 + 3단 계단 + 주묵 사각 | 후보. 주묵이 획 끝에 붙어 있다 |
| `a2-dense.png` | 계선 9 + 상승 끝단 자체가 주묵 | **탈락 — 모서리가 둥글다**(알약 금지 위반) |
| `a3-frame.png` | 사주단변 프레임 + 판면 | 프레임이 내용을 이겼다. 주묵이 공중에 떠 있다 |
| `a4-minimal.png` | 계선 2 + 2단 계단 | 작은 크기 후보. 주묵이 획에서 떨어졌다 |

## `_check-16px.png` 이 말하는 것

윗줄은 16px 로 줄였다 되키운 것, 아랫줄은 24px 흑백 실루엣이다.

**hairline 계선은 16px 에서 전부 증발한다.** 넷 다 굵은 계단 획만 남아
'상승 화살표'로 읽히고, 판면이라는 절반이 사라진다. `a3` 은 금박 프레임만
남고 안이 부서진다.

→ 화면 크기에 따라 **두 벌**로 간다. 큰 판(소개·OG·인쇄)은 `a1`,
헤더·파비콘·앱아이콘은 `a4` 계열로 계선을 2줄까지 줄이고 굵힌다.
사이트의 `AppRule.hair = 0.7` 을 로고에 그대로 가져올 수 없다는 뜻이다.

## 다음에 고칠 것

1. 주묵을 획 **끝에 붙인다** (`a1` 만 붙어 있다). 떨어지면 점이 따로 논다.
2. 모서리를 못 박는다 — `a2` 처럼 둥근 캡이 나오면 그 자리에서 탈락이다.
3. 계단이 판면 아래를 뚫고 나간다. 괘선 블록 안에서 시작하고 끝나야 한다.
