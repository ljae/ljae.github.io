# 로고 시안 — A안 「판면 + 경로」 (2026-08-29)

실록 판면의 세로 괘선(계선) 다섯 줄 중 하나가 계단처럼 올라간다.
**기록(계선)과 테크트리(경로)를 한 그림**으로 둔 것이 이 안의 전부다.
주묵은 도착점 하나에만 찍는다 — 도장을 브랜딩에 쓰지 않기 위해서다
(`theme.dart`: "도장은 단정할 수 있는 것에만 찍는다").

생성: Gemini 3 Pro Image (nano-banana-pro).
**시안까지다.** 최종은 SVG 로 다시 그린다 — 획 두께가 `AppRule` 토큰
(0.7/1.0/2.0/3.0)인 디자인에서 래스터는 규칙을 지킬 수 없다.

## 1회차 (`*.png`)

| 파일 | 구성 | 판정 |
|---|---|---|
| `a1-canon.png` | 계선 5 + 3단 계단 + 주묵 사각 | 후보. 주묵이 획 끝에 붙은 유일한 것 |
| `a2-dense.png` | 계선 9 + 상승 끝단이 주묵 | **탈락 — 모서리가 둥글다**(알약 금지) |
| `a3-frame.png` | 사주단변 프레임 + 판면 | 프레임이 내용을 이겼다 |
| `a4-minimal.png` | 계선 2 + 2단 계단 | 작은 판 후보 |

`_check-16px.png`: **hairline 계선은 16px 에서 전부 증발한다.** 굵은 계단만
남아 '상승 화살표'로 읽히고 판면이라는 절반이 사라진다. → 큰 판·작은 판을
두 벌로 나눠야 한다. `AppRule.hair = 0.7` 을 로고에 그대로 못 가져온다.

## 2회차 (`r2/`) — 1회차의 셋을 못 박고 다시

각진 캡·미터 코너 / 주묵을 획 끝에 접함 / 계단을 괘선 블록 안에 가둠.

| 파일 | 판정 |
|---|---|
| `r2/b1-page.png` | **큰 판 채택.** 판면이 온전히 읽히는 유일한 것 |
| `r2/b2-page-heavy.png` | **탈락 — 막대그래프가 됐다** |
| `r2/b3-compact.png` | 프레임이 생겨 '격자'로 읽힌다 |
| `r2/b4-minimal.png` | **작은 판 채택.** 16px 에서 형태가 온전한 유일한 것 |

**여기서 배운 것: 계선을 굵히면 판면이 차트로 뒤집힌다.** b2 가 그 증거다 —
계선 사이 흰 칸이 막대로 읽혀, 네거티브에 넣어 둔 `chart bars` 가 그대로
나왔다. "작은 판은 굵히면 된다"는 1회차 결론은 절반만 맞았다. 굵히되
**계선 수를 함께 줄여야** 한다(b4 의 방향).

## 최종 (`final/`, 4K, 편집 모드로 형태 보존)

- `logo-large.png` ← b1. 주묵이 획 폭과 일치하고, 상단 획이 계선을 가로지른다.
  **계단이 3단 → 2단으로 줄었다**(요청하지 않은 변화).
- `logo-small.png` ← b4. `_check-16-32px.png` 에서 16·32px 모두 또렷하다.

### 남은 결함 — 두 벌이 한 가족으로 안 보인다

`logo-small` 은 계선 위의 경로가 아니라 **책 표지**로 읽히고, 주묵도 획보다
넓어 `logo-large` 의 규칙과 어긋난다. 로고 시스템에서 작은 판은 큰 판의
**축약**이어야 하는데 지금은 별개 도안이다.

→ 다음 회차: `logo-large` 의 계단을 그대로 두고 계선만 5 → 2 줄로 줄여
  작은 판을 다시 만든다. 주묵 폭은 두 벌 모두 획 폭과 같게 못 박는다.
