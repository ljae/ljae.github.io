# 관(館) 통합 — 한 학원이 여러 등록·건물로 갈라져 있을 때

NEIS 는 관·과정 단위로 따로 등록한다. 목동 씨앤씨는 20개 주소 27건이었다.

`dedupe.py` 의 층위:
1. 같은 주소 + 브랜드 접두사 일치 (기본)
2. 같은 학군 + **관 표기만 지운 이름이 같음** + 한쪽에 관 표기
   (`제N관`·`N관`·`신관`·`본관`·`별관`) 존재 → 통합. 419건 흡수.

함정 기록:
- '씨앤씨'라는 등록은 NEIS 에 없다 — 통합이 만든 **대표명**이다.
  원본 이름으로 견주면 아무것도 안 걸린다.
- 약(light) 토큰은 지역어를 떼므로 지점끼리 합쳐진다(리드101 도곡·대치·
  개포). 관 표기만 지우고 **지역어는 남긴다**.
- 관 표기가 없는 곳끼리는 묶지 않는다 — '피아노교습소(권춘자)'와
  '(김옥선)'은 원장이 다른 남남이다.
- 통합체 이름에 관 번호를 남기지 않는다('길벗제2관' → '길벗보습학원').
- **별도 법인·별도 사이트는 합치지 않는다**: 하이씨앤씨(gohicnc.com)는
  씨앤씨(cncstudy.com)와 협력 관계지만 자체 등록번호·고등부 운영이라
  따로 둔다. 학부모가 구분해 부르는 이름을 합치면 화면이 현실보다
  덜 알려 준다.
