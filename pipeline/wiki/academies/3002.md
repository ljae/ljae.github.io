# 씨앤씨학원 (목동)

[[관-통합]]의 대표 사례. 20개 주소 27건 등록 중 23건이 이 id 로 통합됐다
(2026-08-24, 관 표기 기준 통합 도입).

- **하이씨앤씨(별도 페이지 없음)는 합치지 않는다.** cncstudy.com 이
  신관하이씨앤씨를 목동관으로 소개하지만, 하이씨앤씨는 자체 사이트
  (gohicnc.com)·별도 등록번호로 고등부를 따로 운영한다.
- 씨앤씨미술학원·씨앤씨영재입시학원·더퍼스트씨앤씨학원도 별개다.
- 통합으로 registration_ids 가 흡수되므로, 언급 재귀속(alias 매핑)이
  이 id 로 몰아 준다. 표본 220건 안팎.
