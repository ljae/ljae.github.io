# 분류 위키 — 스키마

이 디렉터리는 **학원 분류 지식의 위키**다. 구조는 karpathy 의 LLM wiki
패턴(원자료 / 위키 / 스키마 3계층)을 따른다.

- **원자료(불변)**: NEIS 원본(`pipeline/.cache/neis_raw.json`), 네이버 언급
  캐시(`naver_mentions.json`), Supabase 의 판정(`mention_reviews`)과
  규칙(`crawl_rules`). 위키는 이것들을 **읽기만** 한다.
- **위키(이 디렉터리)**: 학원 엔티티 페이지와 분류 개념 페이지.
  파이프라인이 매 실행 기계적으로 갱신하는 부분과, 사람/LLM 이 판단으로
  쓰는 산문이 한 파일에 공존한다.
- **스키마(이 문서)**: 페이지 규약과 성장 절차. LLM 세션(Claude Code)이
  위키를 손볼 때 이 문서가 지침이다.

## 페이지 종류

```
index.md            전체 목록 (전부 자동 생성 — 손대지 말 것)
log.md              실행 일지 (자동 append — 손대지 말 것)
concepts/*.md       분류 개념·함정. 사람/LLM 이 쓴다. CLAUDE.md 의 교훈 중
                    '글을 학원에 붙이는 일' 에 관한 것의 상세판.
academies/<id>.md   학원 엔티티 페이지. id 는 NEIS 학원지정번호.
```

## 학원 페이지 구조

```markdown
---
id: "22162"                # 필수. 파일명과 같아야 한다
name: 시매쓰학원            # 참고용 (등록명이 바뀌면 엔진이 경고)
region: banpo              # 참고용
# ↓ 엔진이 실제로 읽는 필드. 없으면 그 힌트는 없음.
aliases: [PEAI]            # 검색·매칭에 추가할 표기 (영문 약칭, 옛 이름…)
generic: true              # 이름이 일상어 → 학원 표지 요구를 강제
exclude_title: [뮤지컬]     # 제목에 있으면 이 학원 글이 아님
exclude_any: []            # 제목+본문 어디든 있으면 제외
locality: [방배]           # 같은 학군 형제 지점을 가를 동네 말
---
# 시매쓰학원 (서초 방배점)

(산문: 이 학원을 분류할 때 알아야 할 것. 근거 링크·실측 수치와 함께.)

## 판정 이력
<!-- auto:review -->
(자동 — 손대지 말 것)
<!-- /auto:review -->

## 통계
<!-- auto:stats -->
(자동 — 손대지 말 것)
<!-- /auto:stats -->
```

## 규약

1. **`<!-- auto:* -->` 마커 안은 기계 영역이다.** 파이프라인이 통째로
   갈아끼운다. 산문은 마커 밖에만 쓴다. 반대로 파이프라인은 마커 밖을
   절대 건드리지 않는다.
2. **모든 산문 주장에는 근거를 단다.** 실측 수치, 판정, 원문 URL.
   근거 없는 문장은 다음 사람이 지울 수도 고칠 수도 없다.
3. **위키 힌트는 관리자 검수를 대체하지 않는다.** 최종 제외 권한은
   여전히 `crawl_rules` 와 판정(verdict)에 있다. 위키의 exclude 는
   같은 게이트 경로를 지나며 실행 로그에 건수가 찍힌다 — 조용한 제외는
   없다. Supabase 규칙과 겹치는 낱말을 위키에 중복으로 넣지 말 것.
   (규칙은 운영자가 화면에서 끄고 켤 수 있지만 위키 파일은 커밋이다.)
4. **id 가 키다.** 통합(dedupe)으로 id 가 흡수되면 엔진이 경고를 낸다.
   그때 페이지를 대표 id 로 옮기는 것은 사람/LLM 의 일이다.
5. 페이지는 **알게 된 것이 있을 때** 만든다. 등록부 5천 곳 전부의 빈
   껍데기를 만들지 않는다. 자동 생성 조건: 랭킹 진입, 또는 판정·규칙·
   재분류가 그 학원을 건드렸을 때.

## 성장 절차

**매 실행(자동)** — `wiki.update()`:
- 조건에 든 학원의 페이지가 없으면 골격을 만든다.
- auto 블록(통계·판정 이력)을 갈아끼운다.
- `log.md` 에 실행 한 줄을 남긴다. `index.md` 를 다시 만든다.
- 모순을 경고한다: 별칭이 다른 학원과 겹침, exclude 가 자기 이름을 침,
  frontmatter 의 name 이 등록명과 어긋남.

**LLM 세션(수동)** — 사람이 신고를 가져오면:
1. 해당 학원 페이지를 읽는다(없으면 이 스키마대로 만든다).
2. 원자료로 원인을 확인하고, 산문에 **근거와 함께** 기록한다.
3. 엔진이 처리할 수 있는 것이면 frontmatter 힌트로 굳힌다.
4. 같은 함정이 다른 학원에도 보이면 `concepts/` 페이지로 올린다.
5. 판정이 필요한 것이면 위키가 아니라 관리자 검수(`/admin`)로 보낸다.

## 함정 목록 (상세는 concepts/)

- [[동명이인]] — 학원명이 사람 이름과 같다 (윤도영)
- [[일상어-학원명]] — 이름 자체가 일상어다 (책읽기)
- [[나열형-비교글]] — 여러 학원을 늘어놓은 글이 한 곳에 붙는다 (지엘피→피아이)
- [[지점-구분]] — 브랜드 후기를 어느 지점에 붙일 것인가 (에이프릴, 시매쓰)
- [[관-통합]] — 한 학원이 여러 건물·등록으로 갈라져 있다 (씨앤씨)
- [[대표명-함정]] — 통합 대표명이 검색어가 되어 오염원이 된다 (책읽기)
