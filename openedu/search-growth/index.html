Open Edu / Search operations

검색 성과를 읽고,
개선할 일을 정리합니다.

OpenEdu Search Growth는 openedu4u.com 운영자 전용 검색 분석 도구입니다. Google Search Console에서 사이트의 검색 성과를 읽어 유입 변화와 확인할 페이지를 살펴봅니다.

수집한 자료를 바탕으로 비공개 보고서, 개선 과제, 변경·실험 기록을 관리합니다.

Google Search Console 읽기 전용운영자가 승인한 연결로 검색 성과를 조회합니다. 요청 권한은 webmasters.readonly이며, Google의 검색 설정을 자동으로 수정하지 않습니다.

어떤 자료를 보나요?

검색어, 페이지, 날짜, 기기, 국가별 클릭·노출·클릭률(CTR)·평균 게재순위를 분석합니다. Search Console CSV 내보내기 자료도 운영자가 직접 수입할 수 있습니다.

누가 사용할 수 있나요?

등록된 사이트 운영자만 분석 화면에 접근할 수 있습니다. 검색 성과 보고서와 과제·실험 기록은 공개 사이트에 게시하지 않습니다.
