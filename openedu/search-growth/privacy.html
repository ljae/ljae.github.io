개인정보 및 데이터 이용 안내

시행일 · 최종 수정일: 2026년 10월 17일

이 안내는 OpenEdu Search Growth의 Google Search Console 연결과 검색 분석 자료 처리에 적용됩니다. openedu4u.com이나 Open Edu 서비스 전체의 개인정보방침을 대신하지 않습니다.

1. 앱의 목적과 이용하는 데이터

OpenEdu Search Growth는 openedu4u.com 운영자가 검색 유입을 분석하고 개선 과제와 실험 기록을 관리하는 내부 운영 도구입니다. 운영자가 Google 연결을 승인하면 해당 계정의 접근 권한으로 사이트의 Search Console 자료를 조회합니다.

  • 검색어, 페이지 URL, 날짜, 기기, 국가와 검색어·페이지 조합별 검색 성과
  • 클릭 수, 노출 수, 클릭률(CTR), 평균 게재순위
  • 자료의 사이트 속성, 조회 기간, 검색 유형, 수집 출처와 수집 시각
  • 운영자가 직접 수입한 Search Console CSV 자료와 이를 바탕으로 작성한 보고서·과제·변경·실험 기록

요청하는 Google 권한은 https://www.googleapis.com/auth/webmasters.readonly입니다. Google이 안내하는 읽기 전용 권한으로 조회하며 검색 설정을 자동으로 수정하지 않습니다.

2. 데이터 이용과 제공

검색 성과 자료는 사이트의 유입 변화 확인, 확인할 페이지와 개선 과제 정리, 운영 변경과 실험 기록에 사용합니다. 검색 성과 자료를 광고에 이용하거나 판매하지 않으며, 원본과 비공개 분석 보고서를 공개 사이트에 배포하지 않습니다.

Google은 자료의 제공처와 OAuth 인증 제공자입니다. 정기 수집은 GitHub Actions에서 실행하고, 게시된 보고서와 운영 기록은 Supabase에 저장합니다. 이들 서비스는 해당 처리와 저장에 사용됩니다.

3. 저장 위치와 접근 권한

  • 보고서와 운영 기록: Supabase의 비공개 분석 테이블에 저장합니다. 앱에서는 등록된 운영자만 조회·관리할 수 있고, 수집·게시 서버 작업은 서버용 인증으로 접근합니다.
  • 원본과 수집 원장: 운영자가 수입한 원본 CSV·ZIP, 로컬 분석 원장과 보고서는 비공개 로컬 작업 파일로 관리합니다. CI 수집 중 생성되는 원장 등은 실행 환경의 임시 파일이며 현재 수집 workflow는 이를 공개 artifact로 게시하지 않습니다.
  • OAuth 인증 정보: 정기 수집용 클라이언트 정보와 갱신 토큰은 GitHub Secrets로 관리하고 실행할 때 환경변수로 전달하도록 구성돼 있습니다. 액세스 토큰은 Google API 요청 인증에 사용합니다.

검색 성과 원본·분석 보고서·OAuth 토큰은 공개 사이트의 HTML·JavaScript·공개 데이터 파일에 포함하지 않습니다. 비공개 파일과 서버 인증 정보는 운영 권한을 가진 담당자가 관리합니다.

4. 보유와 삭제 요청

검색 성과의 기간 비교와 운영 이력 확인을 위해 수집한 스냅샷과 관련 기록을 보관합니다. 현재 고정된 자동 삭제 기간이나 자동 삭제 기능은 설정돼 있지 않으며, 저장된 자료와 로컬 사본은 운영자가 관리합니다.

5. Google 연결 해제

Google 계정의 서드 파티 앱 및 서비스 연결에서 OpenEdu Search Growth를 찾아 연결 권한을 철회할 수 있습니다. 연결 해제 후에는 새 인증이 필요한 Google 자료 수집을 계속할 수 없습니다.

Google 연결 해제는 이미 저장한 분석 보고서나 로컬 사본을 자동으로 삭제하지 않습니다. 기존 자료의 삭제도 원하면 위 지원 이메일로 함께 요청해 주세요.
