# 버전 비교: 기본 vs 전문가 버전

## 📊 한눈에 보는 비교표

| 항목 | 기본 버전 (v1.0) | 전문가 버전 (v2.0) | 개선 정도 |
|------|-----------------|-------------------|----------|
| **문항 수** | 20개 | 30개 | ⬆️ +50% |
| **하위 척도** | 10개 (암묵적) | 15개 (명시적) | ⬆️ +50% |
| **프로필 유형** | 4개 | 8개 | ⬆️ +100% |
| **가중치 시스템** | ❌ 없음 | ✅ 문항별 가중치 | 🆕 신규 |
| **통계 분석** | 기본 평균 | T-score, Z-score, 백분위 | 🔬 고급 |
| **규준 데이터** | ❌ 없음 | ✅ 10개 학년별 규준 | 🆕 신규 |
| **신뢰도 검증** | ❌ 없음 | ✅ 일관성 검사 | 🆕 신규 |
| **우선순위 분석** | ❌ 없음 | ✅ 개선 영역 식별 | 🆕 신규 |
| **맞춤형 전략** | 일반적 조언 | 조건부 맞춤형 계획 | ⬆️ 개인화 |
| **시각화** | 기본 차트 | 다층 시각화 | ⬆️ 향상 |

## 🎯 세부 비교

### 1. 측정의 정교함

#### v1.0 (기본)
```javascript
// 단순 평균 계산
anxietyScore / anxietyCount
```
- ❌ 모든 문항 동일 중요도
- ❌ 절대 점수만 제공
- ❌ 또래 비교 불가

#### v2.0 (전문가)
```javascript
// 가중 평균 + 표준화
anxietySum / anxietyWeightSum
Z-score = (raw - mean) / SD
T-score = 50 + (Z × 10)
Percentile = normalCDF(Z) × 100
```
- ✅ 문항 중요도 반영
- ✅ 표준점수 제공
- ✅ 백분위 비교
- ✅ 학년별 규준

### 2. 프로필 세분화

#### v1.0 - 4가지 프로필
```
┌─────────────┬─────────────┐
│  신중한     │  도전하는   │
│  준비형     │  용기형     │
├─────────────┼─────────────┤
│  편안한     │  자신감     │
│  관망형     │  넘치는     │
│             │  적극형     │
└─────────────┴─────────────┘
  낮은 의지     높은 의지
```
- 단순 2×2 매트릭스
- 포괄적 분류

#### v2.0 - 8가지 프로필
```
┌──────────┬──────────┬──────────┐
│ 보호가   │ 고군분투 │ 용감한   │
│ 필요한   │ 하는     │ 도전자   │
│ 학습자   │ 전사     │          │
├──────────┼──────────┼──────────┤
│ 망설이는 │ 신중한   │ 자신감   │
│ 학습자   │ 참여자   │ 있는     │
│          │          │ 학습자   │
├──────────┼──────────┼──────────┤
│ 편안한   │          │ 완벽한   │
│ 관망자   │          │ 커뮤니   │
│          │          │ 케이터   │
└──────────┴──────────┴──────────┘
  낮음      보통      높음  (의지)
```
- 3×3 세분화 (실제 8개 사용)
- 정밀한 진단
- 맞춤형 전략

### 3. 피드백의 깊이

#### v1.0 (기본)
```markdown
📊 성향 분석
불안감이 낮고 영어로 소통하려는 의지가 높습니다.

💡 맞춤 학습 팁
- 프레젠테이션이나 토론 활동에 적극 참여하세요
- 다른 친구들을 도와주는 멘토 역할을 해보세요
```
- 일반적 조언
- 모든 학생에게 유사한 내용

#### v2.0 (전문가)
```markdown
📊 종합 성향 분석
영어 불안감이 매우 낮고 의사소통 의지가 탁월합니다.
이상적인 영어 학습자 프로필로, 자신감 있게 다양한
상황에서 영어를 구사할 준비가 되어 있습니다.

💪 주요 강점
- 높은 자신감
- 적극적 참여
- 위험 감수 능력
- 자기주도적 학습

⚠️ 주의 영역
- 과도한 자신감으로 인한 세밀함 부족 가능성

🎯 우선순위 1: 의사소통 불안 (3.8점)
→ 이 영역의 불안을 줄이는 것이 가장 시급합니다.

💡 맞춤형 실행 계획
[불안 > 3.0 조건부 표시]
✓ 소규모 그룹에서 시작하여 점차 확대
✓ 철저한 사전 준비로 자신감 확보
✓ 호흡법, 이완 기법 연습

🏃 실천 과제 (이번 주)
1. 하루 5분 영어 독백 연습 (녹음)
2. 수업 중 최소 1회 자발적 발언
3. 영어 일기 3줄 쓰기
```
- 구체적 강점/약점
- 우선순위 명확
- 실행 가능한 과제
- 조건부 맞춤형 조언

### 4. 통계 정보

#### v1.0
```
불안 수준: 3.2 / 5.0
소통 의지: 3.8 / 5.0
```
- 절대 점수만 제공
- 해석 기준 모호

#### v2.0
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
불안 수준: 3.2 / 5.00
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
표준점수 (T-score):     55.3
백분위 (Percentile):    69%
또래 비교:              평균 이상
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 응답 신뢰도 검증
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
응답 일관성:  🟢 높음
분산:         0.45
완료 시간:    8분
응답 완료율:  100%
```
- 다층적 해석
- 과학적 근거
- 신뢰도 정보

### 5. 시각화

#### v1.0
- 기본 막대 그래프 (2개)
- 간단한 2D 맵
- 정적 디스플레이

#### v2.0
- **15개 하위 척도** 상세 그래프
- **통계 정보 카드** (T-score, 백분위)
- **8영역 위치 맵** (정밀 위치)
- **신뢰도 대시보드** (3개 지표)
- **우선순위 카드** (시각적 강조)
- **애니메이션** (진행 바, 호버 효과)

## 🎓 활용 시나리오 비교

### 시나리오: 중2 학생 "김민지"

#### v1.0 결과
```
프로필: 도전하는 용기형
불안: 3.5 / 의지: 3.8

팁:
- 작은 성공 경험을 많이 쌓아보세요
- 충분히 준비한 후 발표하면 자신감이 생겨요
```
→ 일반적 조언, 다음 행동 불명확

#### v2.0 결과
```
프로필: 용감한 도전자
불안: 3.45 (T=56, 백분위 73%)
의지: 3.82 (T=58, 백분위 79%)

[중2 평균: 불안 3.6, 의지 3.1 대비]
✅ 의지는 평균보다 높음 (우수)
⚠️ 불안도 다소 높은 편

━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎯 우선순위 개선 영역
━━━━━━━━━━━━━━━━━━━━━━━━━━━

1순위: 평가 두려움 (4.2점)
   친구들의 반응을 지나치게 의식합니다.
   → 실수를 학습 과정으로 받아들이는 연습

2순위: 수업 참여 의지 (2.8점)
   적극성은 있지만 수업 중 발언은 꺼립니다.
   → 작은 그룹에서 먼저 시작

━━━━━━━━━━━━━━━━━━━━━━━━━━━
💡 이번 주 실천 과제
━━━━━━━━━━━━━━━━━━━━━━━━━━━

[불안 관리 - 최우선]
✓ 발표 전 3분 호흡법 (복식호흡)
✓ 긍정 자기대화 문구 3개 준비

[참여 증진]
✓ 3명 이하 모둠에서 먼저 발언
✓ 하루 1번 손들기 (틀려도 OK)

━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠️ 교사/학부모 참고
━━━━━━━━━━━━━━━━━━━━━━━━━━━

현재 상태: 용기 있게 도전하지만
          스트레스 수준 높음
권장:      긍정적 피드백 자주 제공
          평가보다 과정 중시
          개별 상담 월 1회 권장
```
→ 구체적 수치, 명확한 우선순위, 실행 가능한 계획

## 🎯 결론

### v1.0 (기본 버전)
- **목적**: 성향 개괄 파악
- **시간**: 5분
- **적용**: 전체 스크리닝
- **장점**: 빠르고 간편
- **한계**: 깊이 부족

### v2.0 (전문가 버전)
- **목적**: 심층 진단 및 개입 계획
- **시간**: 8-10분
- **적용**: 개별 맞춤 지도
- **장점**: 과학적, 실행 가능
- **특징**: 전문가 수준 분석
