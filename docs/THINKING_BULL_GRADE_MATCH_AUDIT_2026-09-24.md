# 생각하는황소 학년·지점 연결 점검 — 2026-09-24

## 확인한 불일치

공식 [수업 내용 FAQ](https://www.thinking-bull.com/faq/?idx=121825933&bmode=view)는 초등 4학년부터 고등 1학년까지 수학을 지도한다고 안내한다. 기존 랭킹 자료는 지점이 서로 다른 주소끼리 합쳐져 후기·등록 학년이 한 엔티티에 섞였고, 공식 서초4관 안내가 NEIS 등록번호 3000029897(고무래로10길 26)에 연결돼 있었다. 실제 효령로 398 등록번호는 3000040159다.

추가로 학년 파서가 `생각하는황소서초2관학원`, `생각하는황소서초3관학원`의 `서초2/3`를 초2·초3으로 잘못 읽었다. 따라서 일부 후기 신호와 낮은 학년 밴드가 잘못 연결된 상태였다.

## 반영

- 생각하는황소는 같은 학군이어도 도로명주소가 다른 관을 하나로 합치지 않는다. 대치·목동·서초 7개 주소별 엔티티를 분리하고 각 원 등록번호를 보존한다.
- 주소가 같은 등록만 같은 엔티티로 통합한다. 후기 검색에 지점 고유 도로명이나 관 번호가 있으면 권역 단서가 아니라 지점 직접 근거로 분류한다.
- 서초2관·서초3관의 숫자를 학년으로 해석하지 않도록 파서를 고쳤다.
- 공식 FAQ의 브랜드 공통 수학 범위(초4~고1)를 7개 등록 주소별 공식 근거로 연결하고 수학 과목을 보강했다. 현재 지점별 개설 반과 모집 여부까지 확인한 것으로 표현하지 않도록 caveat를 둔다.
- 공식 학년 안내 2건의 등록번호도 원 NEIS 주소와 대조했다. 시대인재는 3000032995(도곡로 460), 아이엘이는 23598(도곡로 454)로 조정했다. 코드에서 원 등록주소가 공식 안내 주소와 다르면 근거를 적용하지 않도록 했다.

## 후기 검색과 재채점

Aside CLI 브라우저에서 공식 FAQ와 공개 후기 검색 결과를 확인했다. 서초4관으로 식별되는 카페 글은 3000040159의 후기 페이지에 연결했지만, 과목/작성자 등 독립 표본 기준을 충족하지 않아 점수 표본에는 넣지 않았다. 대치 초4 편입 후기처럼 학군만 확인되고 관이 불분명한 글은 특정 관에 붙이지 않았다.

7개 등록번호를 먼저 대상으로 네이버 검색 API를 돌려 후보 2,746건을 확보한 뒤, Aside 검색에서 확인한 질의 단서와 함께 408개 수집 대상의 검색을 새로 실행했다. 전체 수집 결과는 검색 API 원자료 94,528건이고, 학원별 URL 키로 저장한 누적 저장소는 94,531건이다. 이 값은 검색 후보 건수이며 인정된 후기 표본 수가 아니다. 기본 관련성·중복·지점·작성자 게이트를 통과한 언급 23,144건만 점수와 랭킹에 반영됐다. 최종 파이프라인은 408개 분석 대상 중 74개를 랭킹에 노출했다.

## 재채점 결과

7개 지점은 모두 수학 `초4~초6·중등·고등` 브랜드 공통 범위로 연결됐다. 지점별 후기 유효 표본은 대치 본관 2, 대치 관(역삼로 448) 4, 목동 본점 0, 목동 3관 0, 서초 본관·2관 12, 서초 3관 1, 서초 4관 0건이다. 최소 표본 기준을 넘은 서초 본관·2관만 현재 랭킹에 노출된다. 다른 지점의 학년 범위는 표시하지만 표본이 부족해 순위를 만들지 않는다.

## 범위

공식 브랜드 FAQ는 프로그램의 공통 범위다. 각 지점에서 지금 모집 중인 반, 실제 개설 학년, 시간표는 별도 확인이 필요하다. 학년 안내는 후기 수나 랭킹 점수에 가산하지 않는다.

## 2026-09-24 재점검: 수집 누락과 지점 표시

후속 점검에서 더 큰 원인을 찾았다. 생각하는황소 NEIS 등록은 교습과정이 `보습·논술`로만 들어와 파이프라인이 과목을 `general`로 분류한다. 브랜드 매칭은 이를 수학 시드와 충돌한다고 보고 거부해, 브랜드 단계·별칭·후기 수집 우선순위가 붙지 않았다. `general`은 과목 반증이 아니라 미확인으로 처리하도록 고쳤다. 수학 근거가 명시적으로 충돌할 때는 기존처럼 브랜드 연결을 막는다.

대치의 두 표시는 중복 캠퍼스가 아니다. 공식 [전국 지점 안내](https://www.thinking-bull.com/branch)는 대치 본관과 대치 3관을 별도 직영점으로 표시한다. 2024년 강남서초교육지원청 [등록 학원 현황](https://gnscedu.sen.go.kr/CMS/civilapp/civilapp0a/civilapp0a01/civilapp0a0101/1339236_4468.html)은 역삼로 448에 생각하는황소3관·4관·5관이 각 층별 별도 법인명으로 등록됐음을 확인한다. 이 세 등록은 같은 주소의 한 캠퍼스로 합쳐 후기·순위도 한 번만 센다. 영동대로 302 본관은 다른 주소의 별도 캠퍼스로 유지한다. 화면에는 `대치 본관`과 `대치 3관`으로 구분해 보인다.

## 저학년 대상과 선호 근거

학년 필터의 뜻을 둘로 나눠 기록한다. 공식 [신입생 모집 안내](https://www.thinking-bull.com/student1)는 현 초2·초3(예비 초3·초4)을 초4-1 시작반 입학시험 대상으로 밝힌다. 이는 초2·초3 재원 과정과 같지 않다. 한편 [중앙일보 보도](https://www.joongang.co.kr/article/25396275)는 실제 초2 재원 사례를 다루며, 학원 대표가 초2 입학을 허용했지만 권장하지 않는다고 말한 내용을 전한다. 이 때문에 초등 저학년 랭킹에는 `입학시험 대상` 근거가 보이되, 초1 저학년 정규반을 공식 안내가 보장하는 것처럼 쓰지 않는다.

진입 경쟁과 선호는 다음 자료로 출처 패널에 공개한다.

- [한겨레 보도](https://www.hani.co.kr/arti/society/schooling/1165801.html)는 2024년 대치 특정 신입생 시험에서 약 1,800명 지원, 330명 모집을 전했다. 전국 합격률이 아니라 해당 회차 보도다.
- [시사저널e 보도](https://www.sisajournal-e.com/news/articleView.html?idxno=412690)는 초2·초3 시험을 앞둔 준비 수요와 높은 인기를 다뤘다. 대표 선호도 조사는 아니다.
- [강남엄마 대치 3관 후기](https://www.gangmom.kr/institute/65b7af89b83683813731448e)는 확인일 기준 리뷰 32건과 추천 24명을 표시했다. 해당 플랫폼에 올라온 해당 지점 집계다.

이들 집계는 출처와 한계를 명시해 공개하지만 전체 점수에 상수로 더하지 않는다. 점수는 학부모가 실제로 남긴 수집 후기와 인정된 진입 사건으로 계산하고, 파이프라인은 생각하는황소 지점들을 수집 우선순위 100으로 매 회차 먼저 확인한다. 자료 대장은 `pipeline/data/academy_research_sources.json`, 공식 학년 근거는 `pipeline/data/grade_sources.json`, 매칭·우선순위 규칙은 `pipeline/edutree/build.py`, 회귀 검사는 `pipeline/tests/test_selection.py`와 `pipeline/tests/test_grade_sources.py`에 둔다. 외부 집계는 확인 후 90일이 지나면 앱 출처 패널에서 자동으로 빠진다.
