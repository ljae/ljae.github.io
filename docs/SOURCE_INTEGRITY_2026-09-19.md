# 출처 확대와 후기 검증 — 2026-09-19

## 실제 연결 확인

Aside CLI 1.26.916.1741의 `aside repl`로 강남엄마·학원의신을 열고 DOM을 확인했다. `aside exec`는 모델 계정 크레딧 부족(402)으로 실패했지만 브라우저 연결 자체는 정상이다. 네이버 클라우드 콘솔은 로그인 화면이므로 API 설정을 변경하지 않았다.

- [강남엄마 공개 탐색](https://www.gangmom.kr/browse): 공개 소개 목록에서 상세 URL과 다음 페이지를 발견한다. 등록명과 주소가 맞는 학원만 연결한다. 로컬 최초 확인 20곳 중 12곳 연결, 8곳 불일치/불명으로 보류. 후기와 별점은 수집·채점하지 않는다.
- [학원의신](https://academy.hakwonsin.co.kr/): 브라우저에서는 열리지만 자동 요청/robots 확인은 HTTP 429 보안 차단. 자동 수집 출처로 등록하지 않았다.
- 오늘학교: 기존 프로젝트의 robots/Content-Signal 정책상 자동 수집 보류를 유지한다.
- 네이버 검색 API: 실제 호출 결과 카페·블로그 성공, 지식인·웹문서·뉴스는 애플리케이션 비활성 응답. 다음 신규 수집에서 다시 확인하며, 권한이 활성화되면 기존 수집기가 자동 사용한다.
- 공식 홈페이지: 수동 위키 링크뿐 아니라 등록 주소와 대조해 확보한 홈페이지까지 순환 관측한다. robots 확인을 유지하며 관측값은 후기 점수에 사용하지 않는다.

## 반복 갱신

기존 매일 04:00 KST 수집·재채점·배포를 유지한다. 학군별 수집 예산의 최대 20%를 미수집/가장 오래된 학원에 배정한다(기존 순위 학원 갱신 보호 후 남은 예산 범위). 학원 소개는 14일 주기로 재확인하고 공개 목록 페이지 큐를 다음 회차에 이어서 돈다. API 비활성 여부·오류·응답 건수·확인 시각은 `meta.json`의 `rankingQuality.sourceHealth`와 Actions 실행 요약에 남긴다. 429 무한 재시도를 세 번으로 제한한다. 수집 작업 중복 실행을 직렬화하고 CI에서 `.env`가 없어 정정 요청 보고가 실패하던 오류를 수정했다.

## 근거의 용도

뉴스·일반 웹문서·지식인·경험 진술 없는 질문·학원 모집 안내는 독립 후기 점수에서 제외한다. 원자료는 누적 저장소에 남긴다. 카페명·플랫폼 도메인을 개인 작성자로 취급하지 않으며 기존 캐시도 재채점 때 교정한다. 네이버 블로그의 모바일/PC/PostView URL은 같은 문서로 중복 판정한다. 대가성 고지에 지급·협찬 표현을 추가한다.

동명 학원이 여럿 남을 때 검색 결과의 academy_key/prefer를 동일성 증거로 사용하지 않는다. 구·동이 생략된 현재 강남엄마 제목 형식은 등록명과 도로명 건물번호가 유일하게 일치할 때만 연결한다. 기존 지역/지점/일상어/교재 이름 검증도 그대로 적용한다.

이미 생성한 AI 프로필도 매번 현재 유효 근거와 대조한다. 제외된 글을 인용한 문장은 캐시에 있더라도 공개하지 않는다. 검증한 학원 소개의 대상·과목·셔틀은 `directory_sources.json`으로 공개하며 앱 출처 카드에 확인일과 '학원 소개 · 주소 대조'를 표시한다. 소개를 '공식 안내'나 독립 수강 후기로 표시하지 않는다.
