전체 분석: 아티팩트 「학원실록 경쟁 지형도」.
경쟁 축은 학원소개 서비스만 본다(오늘학교 아카데미·런즈·학원어디가·학원신·디스쿨·오르비).
부동산(아실·호갱노노)은 참고만 한다 — 우리는 집이 아니라 학원을 고르는 도구다.

**자리:** 전국형은 넓고 얕고, 커뮤니티형은 깊고 닫혀 있다.
그 사이 — 좁은 학군을 공개된 산식으로 깊게 — 가 우리 자리다.

## 반영됨
- 긍정률(별점·추천율 대응) — 의견 낸 후기 중 긍정 비율, 산식 페이지에 정의
- 정정 요청 창구 — 로그인 없이 접수, 운영자 검토 후 반영 (supabase/06)
  + 처리 대장 `pipeline/corrections_report.py`, 야간 워크플로가 미처리 건을 띄운다
- 후기 구조화 태그 — 학년구간·과목·통제 어휘 15개
- **태그 기반 후기 필터** — 후기 4건부터, 실제 달린 값만 선택지로
- 랭킹 상세 필터 — 정렬 4축 + 교습비 공개·공식 검증
- **재원 인증 배지** — 요청 → 운영자 확인 → 평판 가중치 상승(0.9 → 0.96)
  증빙 이미지는 저장하지 않는다(영수증에 이름·연락처가 함께 찍힌다)
- **학교 진로 랭킹 화면** — 중학교 특목·자사 진학률, 고교 대학 진학률.
  공시 3곳 미만이면 표시하지 않는다
- **레벨테스트 일정판** — 학원 공지/학부모 제보 구분 표시 (supabase/08)
