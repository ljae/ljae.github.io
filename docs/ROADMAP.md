# 로드맵 — 경쟁 분석 기반 (2026-08-23)

전체 분석: claude.ai/code 아티팩트 「학원실록 경쟁 지형도」.
경쟁 축은 학원소개 서비스만 본다(오늘학교 아카데미·런즈·학원어디가·학원신·디스쿨·오르비).
부동산(아실·호갱노노)은 참고만 한다 — 우리는 집이 아니라 학원을 고르는 도구다.

**자리:** 전국형은 넓고 얕고, 커뮤니티형은 깊고 닫혀 있다.
그 사이 — 좁은 학군을 공개된 산식으로 깊게 — 가 우리 자리다.

## 반영됨 (이번 사이클)
- 긍정률(별점·추천율 대응) — 의견 낸 후기 중 긍정 비율, 산식 페이지에 정의
- 정정 요청 창구 — 학원 상세에서 로그인 없이 접수, 운영자 검토 후 반영 (supabase/06)
- 후기 구조화 태그 — 학년구간·과목·통제 어휘 15개
- 랭킹 상세 필터 — 정렬 4축(트리스코어·긍정률·표본·교습비) + 교습비 공개·공식 검증
- 진로 공시 수집기(pipeline/edutree/careers.py) + 학교 시트 표시 — 데이터 수집 중

## P0 (즉시)
- [ ] 진로 공시 수집 완료 확인 (`python3 pipeline/run.py --careers`, 2초 간격 준수)
- [ ] 신규 편입 학원 언급 안정화 (에디센·PEAI·트윈클·알파잉글리쉬 …)
- [ ] 정정 접수 알림·처리 대장 (corrections 테이블 → 운영 메일)

## P1
- [ ] 학교 랭킹: 학군 내 중학교 특목·자사 진학률순 (공시 확보 후)
- [ ] 태그 기반 후기 필터 ('초2 수학 · 관리 꼼꼼'만 보기)
- [ ] 서울대 진학 수기 등재 — 출처 있는 보도값만 (data/school_outcomes_extra.yaml, 빈 상태가 정상)
- [ ] 재원 인증 배지 (증빙 업로드 + 수동 검토)

## P2
- [ ] 레벨테스트 캘린더
- [ ] 학군 확장(중계·평촌) — 기존 4개 학군 품질 안정 후

## 하지 않는다
- 블랙박스 추천 (산식 공개가 존재 이유)
- 학원 광고·상위 노출 상품 (평판 지표를 팔면 지표가 죽는다)
- 없는 데이터로 만든 필터 (시설·셔틀은 NEIS 에 없다)
- 타 커뮤니티 글 전재 (근거는 원문 링크로만)
