# 학원 대상 학년 전수 점검 — 2026-09-19

## 신고와 원인

부엉이학원(등록번호 24352, 도곡로78길 7)이 초등 랭킹에 노출된다는 신고를 조사했다. 공개 자료의 학년은 `elem_low, high`였으나, 부엉이라이브러리(시대인재)·수학하는부엉이학원(역삼로 468)·황금부엉이 출판물 등 다른 대상의 글이 후기와 학년 추정에 섞여 있었다.

검색 API에서 공식 홈페이지로 연결된 블로그 `https://blog.naver.com/owl0652`의 제목은 '대치동 부엉이학원(수능/내신 전문학원)'으로 확인했다. 이는 고등 과정의 단서이지만 현재 모집 학년 전체를 확인한 것은 아니다. 따라서 임의로 '고등만'으로 확정하지 않고, 초등 분류를 철회하고 대상 학년을 미확인으로 처리한다.

기존 공통 로직에도 두 문제가 있었다. `gradeBands=[]`를 전 학년 대상으로 간주했고, 커뮤니티 글에 가까이 등장하는 학년·교재·선행 진도를 학원의 모집 대상으로 추정했다. 단계 추천과 등록부 보충 목록에도 동일한 문제가 있었다. 기존 공개 분석 대상 1,760곳 중 학년 빈 값은 941곳, 이 중 순위 기준을 충족한 곳은 37곳이었다.

## 전수 점검 범위와 판정

교육청 NEIS 공시를 새로 받아 서비스 범위의 전체 학원을 검사한다. 중복 등록을 묶은 학원은 모든 원래 등록번호의 이름·교습과정명·교습비 항목의 과정명을 함께 대조한다. 금액은 사용하지 않는다.

- 학년이 명시된 등록명·과정만 필터 근거로 사용한다. 초등 저/고학년·숫자 범위·예비 학년을 구분한다.
- 연산·사고력·파닉스·의대·교재명만으로 대상 학년을 확정하지 않는다. 선행 과정과 분리할 수 없는 문구는 보류한다.
- 초등 영어와 고등 수학 등 과목별 대상은 분리한다. 복합 문구에서 과목별 학년을 분리할 수 없으면 보류한다.
- 후기 학년과 브랜드 공통 단계는 검토 단서일 뿐, 지점의 대상 학년으로 확정하지 않는다.
- 미확인 학원은 전체 검색과 상세 페이지에 남기되 학년별 랭킹·표본 부족 목록·단계 추천·등록부 보충 목록에는 자동 포함하지 않는다.
- 주소·등록번호를 대조한 공식 지점 안내도 별도 출처로 사용한다. 공통 프로그램만 확인한 경우 지점별 현재 모집 확인과 구분해 표시한다.
- 공시 과정이 있다는 것은 현재 모집 학년을 직접 확인했다는 의미가 아니다. 상세 상담 항목에 출처 기준과 현재 모집 여부 확인 필요성을 표시한다.

전체 판정은 매 수집·재채점 때 `app/assets/data/grade_targets.json`으로 내보낸다. 학원별 등록번호, 근거 필드·문구, 과목별 학년, 보류 문구, 후기 검토 단서와 미확인 상태를 보존한다. `meta.json.gradeTargetAudit`에는 전체 건수와 상태별 집계를 기록한다.

`collect.yml`의 `rescore_only=true, refresh_neis=true`로 네이버 전체 재수집 없이 최신 교육청 공시와 누적 원자료를 재검증할 수 있다. 필터/산식 버전은 `2026-09-19.5`로 바꿔 이전 기준과 순위 변화를 직접 비교하지 않는다.
