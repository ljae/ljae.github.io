## 디자인과 정보 순서

기존 이름 **학원실록**은 유지하고 따뜻한 회녹색 배경, 녹색 탐색 버튼, 흰 정보 카드, 큰 본문 글자와 여유 있는 줄간격으로 통일했다. 모바일 하단 메뉴에서 학원 탐색을 홈 다음에 배치했다.

- 홈: 검색 → 지역·학년·과목 → 학원 카드 → 탐색/지도/학습 경로 → 데이터 기준.
- 카드: 실제 학원명 → 대상·공시 확인 → 도로명 주소 → 과정·후기 요약 → 비용 확인 → 분석 근거.
- 상세: 대상·주소·비용·시간 요약 → 전화/공식 홈페이지 → 공식 등록 정보 → 점수·후기 분석.
- 목록 검색이나 공시 확인 필터를 적용해도 원래 조건의 순위 숫자를 다시 매기지 않는다.

현재 번들에는 비교 가능한 교습비 금액이 없다. 무료나 0원으로 표시하지 않고 자료 부재와 교재비 포함 여부를 확인할 필요를 명시한다. 수업 시간도 충분한 근거를 갖춘 기존 사실 카드 값만 요약한다. 공시 확인은 등록 정보에 대한 확인이며 후기 내용의 진실성을 인증하는 표시가 아니다.

## 정합성 보강

- 원고료·수강권·경제적 대가 제공을 명시한 문장은 다른 광고 표현이 하나도 없어도 제외한다. 공백·개행·제로폭 문자로 분리된 고지도 정규화한다.
- 광고 제외 사유를 `sponsored`와 `promotional`로 기록한다. 비슷한 원고·작성자 집중 게시 필터를 유지한다.
- 같은 학군의 동명 지점은 넓은 지역명만으로 식별하지 않는다. 지점 고유 동네나 고유 등록명 단서가 없으면 `local_unknown`으로 보류한다. 타 권역에서 재귀속하는 경우에도 동일한 판정을 적용한다.
- `ranking_quality.json`에 광고 등 제외 사유별 건수, 관련성·지점 게이트 집계, 필터 버전을 남긴다. 이는 정답률이 아니라 운영 점검용 집계다.
- 대가 없는 후기, 특정 지점이 명확한 후기, 단일 학원은 보존하는 대조 테스트를 추가했다.

자동 판정은 완벽하지 않다. 보류된 지점의 글을 살리려면 확인된 주소·지점 별칭 등 식별 근거를 추가하거나 기존 글 단위 운영자 재분류 절차를 사용한다. 판별 문턱을 내려 불명확한 글을 여러 지점에 복제하지 않는다.

## 검증 결과와 적용 범위

- Python 회귀 테스트 395개 통과. 광고 고지·비광고 대조·동명 지점·정상 지점·품질 집계를 포함한다.
- Flutter 테스트 95개 통과. 320/375/768/1440px, 밝은/어두운 테마, 필터 변경 후 순위 보존을 확인했다.
- Flutter 정적 분석과 웹 릴리스 빌드 통과.
- Aside에서 1440px 브라우저의 홈·검색·학원 탐색 동작을 확인했다. Aside의 뷰포트 변경 API가 지원되지 않아 모바일 브라우저 실측은 수행하지 못했고, 모바일은 Flutter 레이아웃 테스트로 검증했다.
- 1차 비교에서 동일한 로컬 캐시 50,228개 수집 레코드에 기존 코드와 변경 코드를 각각 실행했다. 유효 근거 6,254 → 5,370건, 전체 순위 대상 66 → 52곳. 새 지점 판별에서 1,423건을 보류하고, 대가 고지로 16건을 제외했다. 이 수치는 정답률이나 서비스 전체 개선율이 아니다.
- 로컬 캐시의 채점 대상(584곳)은 현재 배포 번들의 1,598곳보다 적다. 격리된 `/tmp` 복사본에서만 재채점했고, 기존 앱 데이터·위키를 덮어쓰지 않았다. 새 필터를 서비스 데이터에 적용하려면 최신 저장소가 있는 수집 환경에서 재채점해야 한다.
- 코드 변경은 로컬 작업본에 적용했다. 원격 배포는 수행하지 않았다.
