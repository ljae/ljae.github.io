# 랭킹 구조 검토 및 개선 (2026-09-17)

## 현재 구조

수집 대상을 순환 선정하고, 원본 언급을 저장소에 누적한다. 매 회차 이름·지점·중복·과목·주장 판정을 다시 거친 후 지역×과목 코호트로 채점한다. 앱은 충분한 표본과 필수 기둥을 갖춘 학원을 먼저 표시한다. 사용자 신고는 사례 대장과 회귀 픽스처로 이어진다.

이 구조는 유지할 가치가 있다. 특히 원본과 판정을 분리했으므로 판정 규칙을 개선하면 과거에 모아 둔 근거에도 적용할 수 있다. 다만 수집량이나 순위 대상 수의 증가 자체가 정확도 개선을 뜻하지는 않는다.

## 이번 수정

| 문제 | 보완 |
|---|---|
| 180일 반감기로 공개했지만 실제로는 180일 후 약 0.368 | `exp(-ln(2)×일수/180)`으로 수정. 180일 후 0.5, 360일 후 0.25 |
| 발견일이 작성일처럼 최신성·최근 90일 언급 수·진입 사건 최신일에 반영 | 실제 작성일만 사용. 날짜 미상·발견일·미래 날짜는 가중치 0.6, 최근 언급·추세에서는 제외 |
| 원본 저장소가 날짜 출처를 버리고 발견일을 실제 작성일로 교정하지 못함 | `date_source` 보존, 실제 작성일을 추가 확보하면 발견일 대체. 재수집 발견일로 실제 작성일을 덮지 않음 |
| 대표 등수 배정 함수가 다른 과목을 같은 지역 순위로 비교 | 대표 등수도 지역×과목으로 묶음. 과목별 재배정과 함께 탈락 행의 오래된 등수 제거 |
| 같은 날 재채점에서 탈락한 학원의 이전 등수가 이력에 남음 | 해당 날짜를 교체한 뒤 현재 순위만 기록 |
| 이력 보존 기간이 실제 180일이 아니라 수집 180회 | 달력 기준 최근 180일 보존, 임시 파일을 통한 원자적 교체 |
| 산식이나 과목이 달라도 차트가 같은 추이로 연결 | 이력에 산식 버전·지역·과목·비교 대상 수 저장. 앱은 최신 기준과 같은 연속 구간만 표시 |
| 데모 실행이 실제 순위 이력에 섞임 | 실제 데이터 모드에서만 순위·품질 이력 기록 |
| 품질 지표가 현재 회차만 보여 퇴행을 비교하기 어려움 | 일별 `ranking_quality.json` 기록과 이전 날짜 대비 경고 추가 |
| 야간 수집이 Python 회귀 검증 없이 데이터 게시 단계로 진행 | 수집 전에 전체 파이프라인 테스트 실행 |

기둥별 가중치는 변경하지 않았다. README의 오래된 가중치, SPEC의 화제성 계수와 반감기 식, 앱의 최신성 설명을 실제 계산과 맞췄다.

## 반복 개선에 쓰는 기록

`meta.json`의 `scoringVersion`과 `rankingQuality`는 이번 계산 기준과 상태다. `app/assets/data/ranking_quality.json`은 같은 상태를 날짜별로 180일간 보존한다. 기존 야간 커밋 경로에 포함되어 다음 실행에서도 비교할 수 있다.

기록하는 값은 전체/유효 근거 수, 실제 작성일 확인 건수와 비율, 출처별 유효 근거 수, 지역×과목별 평가·근거 보유·순위 대상·기둥 미완 수다. 같은 날 재실행은 교체하고 이전 날짜와 비교한다. 산식 버전이 달라지면 변화 경고 비교는 새로 시작한다. 작성일 확인율 또는 순위 대상 수가 감소하면 로그에 원인을 점검할 경고를 남긴다. 감소가 반드시 오류는 아니므로 자동으로 과거 점수를 복원하지 않는다.

권장 점검 순서는 경고가 난 코호트의 수집 실패·날짜 누락을 먼저 확인하고, 관련 신고를 사례 대장으로 추적한 다음, 수정에 회귀 픽스처를 추가하는 것이다. 야간 테스트를 통과한 수정은 다음 수집에서 누적 원본에 재적용된다.

## 해석과 남은 검증 과제

- 품질 기록은 정확도의 정답률이 아니다. 기존 신고 픽스처는 재발 방지 사례이며 전체 수집 결과의 대표 표본도 아니다. 과목·출처별로 사람이 판정한 별도 평가 표본을 확보해야 오귀속률과 감성·주장 판정 정확도를 측정할 수 있다.
- 현재 `confidence`는 표본 수 등급이다. 작성자 독립성이나 출처 편중까지 검증한 통계적 확률로 읽으면 안 된다. 이번에 남기는 출처 분포와 날짜 확인율은 이 한계를 관찰하기 위한 출발점이다.
- Kish 유효 표본수는 모든 가중치를 같은 비율로 줄여도 변하지 않는다. 따라서 동일하게 오래된 후기만 있는 학원의 평판이 최신성 감쇠만으로 평균에 가까워진다고 보장할 수 없다. 신뢰도·표본 기준을 바꾸려면 별도 평가 표본으로 기존 산식과 비교해야 한다.
- 작성일을 나중에 확인하는 경우 점수와 순위가 달라질 수 있다. 이 변경은 근거 보강에 따른 재계산이다. 버전·코호트 정보가 없는 과거 이력은 파일에 보존하지만 새로운 기준의 차트와 연결하지 않는다.
- 최초 코드 검토에서는 운영 데이터를 게시하지 않았다. 이후 재채점·배포 결과는 아래에 기록한다.
