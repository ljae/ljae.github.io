## 2. 즉시 — 랭킹이 지금 틀린 것 (결정 불필요)

### A1. '외국어' 가 '국어' 로 읽힌다 — **가장 급하다**
`실용외국어` 라는 NEIS 표준 교습과정에 **'국어' 가 부분 문자열로 들어 있다.**
CLAUDE.md 가 기록한 '과목어가 낱말 사이에 걸쳐 생긴다' 함정과 같은 것인데,
`_subject_text` 의 이음매 처리가 이 조합을 못 잡았다.

전수: 등록 **74건**이 국어로 잘못 잡혔고, 그중 **25곳이 실제 국어 랭킹**에 있다.

    반포 국어 1위  청담아이가르텐학원    표본 50   ← 영어유치원
    반포 국어 2위  세인트폴              표본 78   ← 영어
    대치 국어 3위  그로튼아카데미학원     표본 32   ← 영어 (신고받은 곳)
    목동 국어 3위  미래탐구              표본 61
    … 그 밖에 중국어·일본어 교습소 다수

- 파일: `pipeline/edutree/build.py::_subject_text` (또는 `_course_signal`)
- 절차: `_subject_text` 가 `'외국어'` 를 `'외 국어'` 로 가르지 않도록,
  **`'외국어'` 를 통째로 지우거나** 이음매 공백을 넣어 `'국어'` 가 생기지 않게 한다.
  `'실용외국어'` 는 영어·중국어·일본어를 아우르는 값이라 **과목 신호로 쓰지 않는다** —
  '보습·논술' 과 같은 처지다(업종 전부가 갖는 값).
- **주의**: 진짜 국어 학원을 깨면 안 된다. `'국어학원'`·`'국어논술'` 은 그대로 살아야 한다.
- 테스트(먼저 쓴다):
  ```python
  def test_실용외국어는_국어가_아니다():
      row = {"name": "그로튼아카데미학원", "realm_sc_nm": "종합(대)",
             "le_crse_nm": None, "le_crse_list_nm": "실용외국어(유아/초·중·고)"}
      assert "korean" not in build._infer_subjects(row)
      row2 = {"name": "권미나국어학원", "realm_sc_nm": "입시.검정 및 보습",
              "le_crse_nm": "보습·논술", "le_crse_list_nm": "보습·논술"}
      assert build._infer_subjects(row2) == ["korean"]      # 이름이 말하는 것은 그대로
  ```
- 완료 조건: 위 테스트 통과 + 전수 재측정에서 `'외국어' 를 가졌는데 국어` 가 **0건**.
  다음 야간 산출물에서 반포 국어 1·2위와 대치 국어 3위가 바뀐다.
