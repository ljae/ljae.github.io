## 판단

두세 학원을 같은 글에서 다룬 자료는 비교의 맥락을 함께 읽는 데 유용하다. 다만 이름을 나열한 홍보 글과 한 곳만 경험한 글도 있어 제목만으로 추천하면 안 된다. 기존 `academies.json`의 같은 URL을 공유한 학원 묶음에서도 목록형·무관한 지점이 섞였다. 공유 URL은 탐색 후보일 뿐 품질 판정이 아니다.

본문에서 학원별 설명 절과 공통 축 2개 이상을 확인한 4편을 링크 목록에 넣었다. 글의 설명이 사실인지 독립 검증한 것은 아니므로, 짧은 읽기 안내와 출처 범위만 제공하고 현재 학원 사실·점수로 전환하지 않는다.

## 구현

- 비교 카드에 선택한 2/3곳 범위, 빠진 학원, 공통 읽기 항목, 작성일·학년, 지점 연결 한계를 표시. 추가 정보에서 실제 본문 확인일·경험/조사 성격·읽을 절을 공개.
- 여섯 축으로 분리: 진도/교재, 오답/첨삭, 숙제, 참여, 입학/이동, 일정/통학. 각 축에 구체적 확인 사항과 선택 의미·질문을 붙임. 무관한 교재 인용이 새 축 전체로 복제되지 않도록 내용 조건을 적용.
- 실제 화면 검토에서 입학 준비를 위한 개인 과외 보충을 학원의 피드백으로 읽을 위험을 확인해 제외 조건을 보강했다. ‘숙제 후 귀가’만 있는 문장도 통학 근거로 중복 표시하지 않는다. 먼저 선택한 관심사의 근거가 없으면 앞에서 질문과 관련 원문으로 안내한다.
- 항목별 원문 연결, 학원별 질문 복사에 관련 비교 글 링크·시점·범위 포함. 기존 문의·학부모 의견 경로 유지. 가격 수치·가격 평가 미생성.
- 자료 로딩 실패와 검토한 글 없음 구별, 원문 열기 실패 시 링크 복사. URL 중복 제거, 과목·학년 필터, 2~3개 정본 ID 기준 연결.
- 조사·설계·검증 agent 프롬프트에 본문 밀도·일부 범위·오귀속 반례와 과거 자료의 취급을 추가. 이번 검증은 주 에이전트 자체 점검이며 독립 하위 에이전트 실행은 없음.
