# 비교 정보의 의미 개선

문제: 기존 비교는 학원별로 같은 ‘미대조’ 안내와 공통 질문을 반복하고, 실제 자료는 건수만 표시했다. 자료가 무엇을 말하는지, 선택에 어떤 영향을 주는지 판단할 수 없었다.

## 변경

`app/lib/data/parent_comparison.dart`의 읽기 전용 변환과 `app/lib/features/compare/compare_page.dart`를 연결했다. 과목·학년을 명시한 뒤 관심사 순으로 진도/질문/피드백, 숙제/가정 부담, 입학 준비를 읽는다. 지점 위치와 직접 문의를 이어 붙인다.

각 행은 공통 선택 관점을 한 번 설명하고 후보별로 **실제 발췌 → 글의 과목·학년·작성일 → 원문 → 현재 반에 확인할 질문**을 표시한다. AI 프로필의 note/load/band/goodFor는 비교 사실이나 추천 결론으로 쓰지 않는다. 주제별 quote는 같은 학원의 evidence URL과 대조해 사용하고, 공개 발췌의 단어 매칭은 관련 글을 찾는 데만 사용한다. 기존 주제 인용을 일반적인 글 앞머리보다 먼저 보여준다.

기존 source_notes의 공식 수업·입학 안내도 정확한 학원 ID·과목·지점 범위로 연결했다. 공식 안내 요약은 따옴표를 쓰지 않고 출처 종류·대조일·기존 caveat를 표시한다. 현재 스키마에는 해당 안내의 학년 필드가 없으므로 ‘선택 학년·반 적용 확인 필요’를 유지한다. 브랜드 공통·다른 과목·다른 지점·디렉터리 자료를 이 칸에 옮기지 않는다. 공식 자료를 불러오지 못하면 별도 재시도를 제공한다.

다른 과목·학년이 명시된 자료, 브랜드 공통/지점 미상 자료, 원문 URL이 없는 인용, 금액·수강료가 들어간 발췌를 제외한다. 미확인 과목·학년은 표시하고 적용 여부를 묻는다. 작성일은 경험 시점이나 현재 운영 인증이 아니다. 공통 공백은 한 섹션으로 묶으며, 공백을 낮은 점수로 바꾸지 않는다.

질문 복사는 해당 학원·선택한 과목/학년·실제 발췌와 원문을 포함한다. 등록번호 별칭은 같은 후보로 묶고, 공유 링크는 학원 목록만 공유한다고 설명한다. 원본 JSON·점수·게이트·Supabase 계약은 변경하지 않았다.

에이전트의 planner/evidence/quality 역할에도 ‘건수·일률적 주의문만 있는 비교는 미완료’라는 수락 기준을 추가했다. 이 작업은 주 담당자의 구현·자체 검증이며 별도의 독립 에이전트 검증으로 표기하지 않는다.

## 검증

- `flutter analyze --no-pub`: 이슈 없음.
- V2 플래그 3개 활성 전체 `flutter test --no-pub`: **152개 통과**. 새 비교 반례 10개를 포함한다. 서로 다른 숙제 경험, 다른 과목/학년/지점 제외, 원문 없는 프로필 제외, 공식 안내의 학원/과목/지점 경계, 출처 종류·날짜·중복, 범위 없는 글, 자료 없는 등록부 학원, 320/768/1440px·200% 글자를 확인했다.
- 동일 플래그의 `flutter build web --no-pub`: 성공.
- `scripts/check_parent_comparison_web.cjs`: 실제 공개 자산 두 쌍으로 관심사 순서, 서로 다른 발췌와 의미, 학년 변경, 해당 학원의 발췌·원문을 포함한 클립보드, 공식 안내/대조일/학년 적용 미확인, 320/375/768/1440px를 확인했다. 페이지/콘솔 오류 없음.
- `git diff --check`: 통과. 사용자 인터뷰와 실제 전화 연결은 이번 검사에 포함하지 않는다.

## 적용 범위와 한계

로컬 Flutter 웹 미리보기까지 적용하며 운영 배포는 하지 않는다. 기존 공개 번들에 포함된 글을 재구성한 것이므로 원문을 이번 작업에서 다시 방문해 검증하거나 현재 반의 운영을 조사한 결과는 아니다. 상세 evidence의 지점/과목/학년 귀속 오류가 있으면 기존 gate 검토가 필요하다. 내용이 없는 학원에 새 차이를 만들어 넣지는 않는다.
