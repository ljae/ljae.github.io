# 데이터 출처와 한계

트리스코어가 무엇을 근거로 계산되는지, 그리고 **무엇을 모르는지** 적어 둔다.
실명 사업자를 점수로 줄 세우는 서비스에서 한계를 감추는 것은 곧 왜곡이다.

---

## 1. 출처별 역할

| 출처 | 채우는 것 | 로그인 | 위험 | 상태 |
|---|---|---|---|---|
| NEIS 학원교습소정보 | 학원 원장 · 교습비 · 정원 · 등록상태 | 불필요 | 없음 (공공데이터) | **가동** |
| 네이버 검색 API (카페글) | 언급 · 평판 신호 | 불필요 | 없음 (공식 API) | **가동** |
| 네이버 검색 API (블로그) | 언급 · 날짜 | 불필요 | 없음 | **가동** |
| 네이버 블로그 본문 | 전문 (스니펫 120자 → 평균 2,000자+) | 불필요 | 없음 (공개 문서) | **가동** |
| 지식iN | 추가 평판 신호 | 불필요 | 없음 | ✗ NCP 앱에서 미활성 |
| 카페 목록 페이지 | 카페글 작성일 | 경우에 따라 | 약관 회색지대 | 선택 (수동) |
| 카페 본문 | 후기 전문 | 필요 (+등업) | **계정 정지 위험** | 권장하지 않음 |

---

## 2. 카페: 어디에 글이 모여 있나

수집한 12,233건(관련성 통과)의 출처를 집계한 결과다. 추측이 아니라 실측이다.

| 카페 | 비중 | 강한 학군 |
|---|---|---|
| `cafe.naver.com/mapacademy` | 최상위 | 반포 17.5% · 잠실 14.6% · 대치 9.9% |
| `cafe.naver.com/studymokdong` | 목동 1위 | 목동 19.8% |
| `cafe.naver.com/mathall` | 수학 전반 | 목동 9.6% · 잠실 8.8% |
| `cafe.naver.com/gangnamchild` | 강남권 | 반포 10.0% · 대치 7.6% |
| `cafe.naver.com/songdoeduall` | 대치 1위 | 대치 10.7% |
| `cafe.naver.com/seochom` | 서초 | 반포 6.4% |

3,135개 카페에 흩어져 있지만 **상위 10개가 전체의 33%** 를 차지한다.

> **가입이 필요한가?** 지금 파이프라인에는 필요 없다. 검색 API 는 로그인 없이
> 스니펫을 준다. 가입은 사람이 직접 후기를 읽고 큐레이션을 손볼 때 쓸모가 있다.
> 대부분의 학원 카페는 **등업** 후에야 후기 게시판이 열린다.

---

## 3. 카페 본문을 긁지 않는 이유

1. **규모가 안 맞는다.** 12,233건을 개별로 열면 13시간 이상 걸리고, 그 전에
   차단된다. 야간 자동 수집에 넣을 수 없다.
2. **계정 위험이 실질적이다.** 자동화로 정지되면 등업 등급까지 잃는다.
   몇 주 걸려 쌓은 접근 권한이 데이터베이스 한 칸과 바꿀 값어치는 없다.
3. **약관 문제.** 카페 본문은 로그인 뒤에 있고, 자동 수집은 네이버 약관에
   어긋난다. 공개 서비스가 이것에 의존하면 방어할 수 없다.

대신 **블로그 본문**을 쓴다. 공개돼 있고, 로그인이 필요 없고, 정지당할 계정
자체가 없다. 스니펫 120자가 평균 2,000자 이상으로 늘어난다.

`pipeline/edutree/cafe_local.py` 와 `cafe_dates.py` 는 직접 판단해 쓰실 수
있도록 남겨 두었다. 둘 다 기본 꺼짐이고 CI 실행을 거부한다.

---

## 4. 날짜: 가장 큰 빈틈

**카페글 검색 API 는 작성일을 주지 않는다.** 수집분의 91%가 날짜 없이 들어온다.
화제성(20%)이 나머지 9%로 계산되던 문제를 세 단계로 메운다.

1. **블로그 본문에서 추출** — 본문 페이지에 작성일이 있다. 자동.
2. **발견 시점 기록** (`discovery.py`) — 매일 도는 수집을 시계로 쓴다.
   어제 없던 URL 이 오늘 보이면 최근 글이다. 크롤링도, 한도 소모도 없다.
   *첫 실행분은 '기준선'으로 표시하고 날짜를 추정하지 않는다.* 전부 오늘
   것으로 처리하면 수년치 글이 오늘 쏟아진 것처럼 보인다. 이 신호는
   **매일 돌수록 좋아진다.**
3. **카페 목록 페이지** (`cafe_dates.py`, 선택) — 목록은 한 번에 10~30건의
   (링크, 날짜) 쌍을 준다. 개별 글을 여는 것보다 트래픽이 3% 수준이다.

### 현재 한계

기준선 이전 글의 절대 작성일은 여전히 모른다. 날짜를 모르는 글에는
**중립 최신성 가중치(0.6)** 를 준다. 최신으로도, 오래된 것으로도 치지 않는다.
화제성은 네 기둥 중 지금 가장 약하며, 운영 기간이 쌓일수록 정확해진다.

## 5. 커버리지

| 항목 | 수치 |
|---|---|
| NEIS 검증 학원 (4개 학군, 학술 분야) | 4,170곳 |
| 트리스코어 채점 | 400곳 (학군당 100) |
| 순위 노출 (유효 표본 10건 이상) | 84곳 |
| 관련성 통과 언급 | 16,361건 |

**왜 4,170곳을 다 채점하지 않는가.** 네이버 한도가 유한하다. 전부 돌면 6만 회를
넘긴다. 학군당 100곳을 우선순위(테크트리 매핑 > 과목 특정 > 정원)로 고르고,
나머지는 등록부에만 남긴다.

미수집 학원에는 **점수를 붙이지 않는다.** 언급 0건으로 채점하면 '보지 않은'
학원이 '평가했는데 낮은' 학원처럼 보인다. 그 둘은 전혀 다른 상태다.

---

## 6. 알려진 왜곡 요인

- **관련성**: 네이버 검색은 느슨하게 관련된 결과를 넓게 준다. 수집분의 69%가
  학원명을 한 번도 언급하지 않아 제외된다. 남은 것도 완벽하지 않다.
- **감성 분석**: 사전 기반이다. 반어법과 맥락을 놓친다.
  `analyze.score_sentiment()` 만 모델로 교체하면 나머지는 그대로 동작한다.
- **광고 판별**: 관련 언급의 약 3%를 걸러낸다. 실제 비율은 더 높을 것이다.
- **진입난이도**: 커뮤니티 언급에서 추정한 값이며 공식 경쟁률이 아니다.
  화면에 항상 '추정' 표시가 붙는다.
- **표본 편중**: 큰 학원일수록 언급이 많다. 베이지안 축소가 소표본의 극단값을
  누르지만, 규모 자체의 유리함을 완전히 없애지는 못한다.
