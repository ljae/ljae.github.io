# 에듀트리 (EduTree) — 제품 사양서

> 대치 · 목동 · 반포 · 잠실 학원 테크트리와 랭킹 플랫폼
> 운영: Open Edu (openedu4u.com)

---

## 1. 제품 정의

### 한 줄 정의
학부모가 **"우리 아이는 지금 어디에 있고, 다음에 어디로 가야 하는가"**를 지도 위에서 보게 하는 서비스.

### 기존 서비스와의 차별점

| | 기존 학원 정보 서비스 | 에듀트리 |
|---|---|---|
| 데이터 | 학원이 직접 올린 홍보 정보 | 공공데이터(NEIS) 검증 + 커뮤니티 신호 |
| 구조 | 목록/검색 (평면) | **테크트리 그래프 (경로)** |
| 랭킹 | 광고비 순 / 없음 | 공개 산식 기반 트리스코어 |
| 범위 | 전국 (얕음) | 4개 학군 (깊음) |

### 핵심 화면 4개
1. **테크트리** — 과목×학년 진학 경로 그래프. 노드=단계, 엣지=진급 경로, 노드 안에 학원 카드.
2. **랭킹** — 지역×과목×학년별 트리스코어 순위. 산식과 근거를 모두 공개.
3. **학원 상세** — 공식 검증 정보 + 평판 분석 + 소속 테크트리 노드 + 근거 원문 링크.
4. **지도** — 4개 학군의 학원 밀도/클러스터.

## 3. 테크트리 데이터 모델

테크트리는 **자동 생성이 불가능**하다. 어떤 공공데이터도 "소마 → 황소" 같은 진급 관계를 담고 있지 않다.
따라서 그래프의 **뼈대(노드/엣지)는 큐레이션**, **살(학원 배치/점수)은 자동 수집**으로 간다.

```
Track (과목 × 학교급)          예: 수학 / 초등
  └─ Stage (단계 노드)          예: 사고력수학 → 경시·심화 → 중등선행 → 내신·수능
       ├─ prerequisite edges    선수 조건 (학년, 선행 진도, 레벨테스트)
       └─ Academy[]             이 단계를 담당하는 학원들 (지역별)
```

### 엔티티
- `track` — 과목(수학/영어/국어·논술/과학) × 학교급(초/중/고)
- `stage` — 트랙 내 단계. `order`, `typical_grade_range`, `goal`, `exit_criteria`
- `stage_edge` — `from_stage → to_stage`, `condition`(선행 정도/레벨테스트/시기), `transition_rate_note`
- `academy_stage` — 학원 ↔ 단계 매핑 (지역별, 대표 강좌명, 반 레벨)

### 큐레이션 원칙
- 엣지는 **커뮤니티에서 반복 관찰되는 경로만** 등재하고, 근거 게시물 수를 함께 저장한다.
- 단정하지 않는다: "일반적으로 관찰되는 경로"로 표기하고 반례 표시를 허용한다.

## 4. 트리스코어 (TreeScore) — 랭킹 산식

0~100점. **네 기둥의 가중합.** 산식 전체를 서비스 내에 공개한다
(`/method`). 이 절은 `pipeline/edutree/scoring.py` · `config.py` 와
**반드시 일치해야 한다** — 어긋나면 공개하는 의미가 없다.

```
TreeScore = 0.35·평판 + 0.35·진입난이도 + 0.15·화제성 + 0.15·투명성
```

가중치의 근거: 학부모가 실제로 묻는 것은 '평이 좋은가'와 '가고 싶어도
갈 수 있는가' 둘이다. 들어가기 어렵다는 사실 자체가 수요의 가장 정직한
표현이라, 자리가 남는 학원과 대기를 거는 학원을 같은 저울에 놓지 않는다.

> **교습비는 어느 기둥에도 없다.** NEIS 는 금액만 주고 **교습시간을 주지
> 않는다** — 주2회 26만원과 주5회 26만원이 같은 값으로 선다. 비교가
> 성립하지 않는 숫자는 정보가 아니라 오해의 원인이다. 투명성의 '교습비
> 공개' 배점도 함께 뺐다(공개여부 필드는 9,324곳 중 9,224곳이 'Y' 라
> 애초에 신호가 없다).

**코호트 = 지역 × 과목.** 상대평가는 언제나 같은 과목끼리다. 학년 구간은
코호트 축이 아니다 — 구간까지 쪼개면 표본이 남지 않는다(§4.7).

### 4.1 평판 (Reputation) — 35%
커뮤니티 후기의 감성을 **신뢰도·최신성으로 가중**한 값.

```
w_i = credibility_i × recency_i
credibility_i = f(본문 길이, 구체적 수치, 1인칭 경험, 수강 이력, 출처)
                × (1 - spam_i)
recency_i     = exp(-Δdays / 180)          # 반감기 6개월, 날짜 불명은 0.6

obs   = Σ(w_i · s_i) / Σ(w_i)              # s_i ∈ [-1, 1]
shrunk = (obs · n_eff + m · μ) / (n_eff + m)     # 베이지안 축소
Reputation = clamp(50 + 15 · (shrunk - μ) / σ)   # 코호트 z 점수
```
- `m` = 사전 표본수(기본 12). **후기 3개짜리 학원이 1위로 튀는 것을 막는다.**
- `n_eff` = 유효 표본수 `(Σw)² / Σw²`. 가중치가 고르면 표본 수와 같고,
  낮은 신뢰도 글이 섞이면 그만큼 줄어든다. **`m` 과 같은 단위여야 한다** —
  가중치 합(Σw)을 그대로 쓰면 글 한 건의 무게가 0.2~0.5 라 표본 30건도
  사전값에 눌린다(실측에서 평판의 실효 기여가 꼴찌였던 원인).
- `μ`·`σ` = 동일 지역×과목 코호트의 **학원 단위** 평균 감성과 표준편차.
  글 단위 편차를 쓰면 글마다의 잡음이 분모에 들어간다.
- **선형 매핑이 아니라 z 점수를 쓰는 이유**: 감성 `[-1,1]` 을 `[0,100]` 에
  선형 매핑했더니 실제 감성이 0.00~0.78 구간에만 살아서 점수가 53~65 로
  눌렸다. 가중치 0.35 인데 순위를 못 가르는 상태였다.
- **바이럴/광고 필터**: 동일 작성자 반복(4건 이상 감쇠), 정형 문구,
  연락처·해시태그 도배로 스팸 점수를 매겨 `credibility` 를 깎고,
  0.35 이상이면 근거에서 아예 배제한다.

### 4.2 화제성 (Momentum) — 15%
```
volume = log(1 + max(최근 90일 언급수, Σ recency_i))
Momentum = 0.6 · clamp(50 + 18 · z(volume)) + 0.4 · clamp(50 + 12 · slope)
```
- 90일 창만 쓰면 91일 된 글과 89일 된 글이 딱딱하게 갈린다. 최신성
  가중합과 **큰 쪽**을 써서 경계를 무르게 한다.
- `z` 는 코호트(지역×과목) 내 정규화. **코호트 분포도 같은 `volume` 식으로
  만든다** — 자기 값과 분포를 다른 자로 재면 z 가 통째로 치우친다.
- `slope` = 12개월 월별 언급 수의 선형 기울기를 **월평균으로 나눈 상대값**.
  절대 기울기는 학원 규모에 딸려 다닌다 — 월 50건이 30건으로 주는 것과
  월 5건이 0건이 되는 것은 같은 '줄어듦' 인데 절대값은 6배 차이가 난다.
- 관측이 없는 달은 **0 으로 채운다.** 빈 달을 건너뛰면 1월과 6월이 인접한
  두 점이 되어, 언급이 끊긴 학원의 하락이 잡히지 않는다.
- **발견일로 채운 날짜는 추세에 쓰지 않는다.** 추세는 '언제 쓰였나' 의
  시계열인데 발견일은 '언제 우리가 봤나' 다. 수집 일정이 곧 x축이 되면
  화살표가 학원이 아니라 우리 크롤 일정을 가리킨다(실측: 발견 도장이
  사흘에 몰려 추세가 잡히는 44곳 중 40곳이 '상승' 이었다). 최신성
  가중치와 90일 창에는 그대로 쓴다 — 거기서는 '최근에 처음 본 글은
  대체로 최근 글' 이라는 논리가 성립한다.
- 그래서 **대부분의 학원은 '보합'** 이다. 실제 작성일을 아는 글이 9%뿐이라
  기울기를 낼 수 있는 곳이 적다. 모르는 것을 모른다고 두는 편이 수집
  일정을 추세로 파는 것보다 낫다.
- 카드의 **상승·하락 화살표**가 이 값이다. 순위 변동과는 다른 값이다.

### 4.3 투명성 (Transparency) — 15%
NEIS 공시 기반 **규칙 채점**. 유일하게 100% 검증 가능한 기둥이다.

| 항목 | 배점 |
|---|---|
| 등록상태 정상 (휴원/폐원 아님) | 30 |
| 정원 · 동시수용인원 공시 | 20 |
| 교습과정·계열 상세 등록 | 25 |
| 운영 지속기간 (개설일 기준, 로그 스케일 · 20년에 만점) | 25 |

### 4.4 진입난이도 (Selectivity) — 35%
커뮤니티 후기에서 **확인된 사건**으로 잰다. 낱말을 세지 않는다 —
'어렵다' 는 말이 아니라 '떨어진 사람이 있다' 는 사실을 본다.
**공식 경쟁률이 아니므로 UI 에 '추정' 을 명시한다.**
```
Selectivity = 0.55·사건강도 + 0.25·확인율 + 0.20·최신성
사건 0건이면 점수를 내지 않는다(None) → 남은 기둥으로 가중치 재정규화
```

| 사건 | 무게 |
|---|---|
| 레벨테스트 탈락 | 1.00 |
| 대기 · 웨이팅 | 0.80 |
| 정원 마감 | 0.60 |
| 어렵게 통과 | 0.50 |
| 레벨테스트 있음 | **0.10** |

- 세 조건을 모두 통과해야 사건이다: 학원 이름 근처(±45자) · 부정문이 아님 ·
  전문·의문이 아님. '레테 어렵다던데 대기 걸리나요?' 는 질문이지 경험이 아니다.
- **종류별로 포화시킨다.** 전부 더하면 약한 신호가 양으로 쌓여 무게를
  상쇄한다. 종류마다 서로 다른 작성자 수로 포화시킨다.
- **표본 수로 나누지 않는다.** '사건이 일어났는가' 이지 '글 중 몇 %가 그
  얘기를 하는가' 가 아니다.
- **'레벨테스트 있음' 의 무게가 0.10 인 이유** (2026-09-05 조정, 이전 0.30).
  전수 조사에서 사건 3,242건의 **89%(2,885건)** 가 이 종류였고, 점수가
  있는 152곳 중 66곳이 이것 하나만 가지고 있었다. 대치·목동 학원가에서
  레벨테스트는 거의 보편적이라 난이도를 가르지 못한다. 그런데도 이 기둥이
  실효 기여 6.10 으로 평판(1.82)의 3.4배였고, 그 값의 73%가 표본 크기로
  설명됐다(log(표본)과 상관 r=0.73). 약한 신호를 버리지는 않되 자리를 낮췄다.
- 최신성을 건다. 3년 전 '대기 걸렸다'와 지난달 '대기 걸렸다'가 같은 무게일
  이유가 없다 — 진입난이도야말로 지금 상황을 말해야 하는 값이다.
- 화면에는 숫자보다 **등급**을 앞세운다. 표본 3건짜리 '난이도 74점' 은
  정밀해 보이지만 그 정밀도가 근거에 없다.
- **등급반별 난이도는 내지 않는다.** 400곳 전체에서 반 이름과 난이도
  표현이 함께 붙은 글이 186건뿐이고, 그중 상당수가 키워드 나열형 광고라
  기초반이 최상위반보다 어렵게 나왔다. 반별 난이도는 큐레이션 테크트리의
  단계별 진입 기준(`exit_criteria`)으로 대신한다.

### 4.5 예체능·기타 — 기둥을 다 적용하지 않는다
```
TreeScore(예체능·기타) = 0.6·평판 + 0.4·화제성
```
- **투명성을 빼는 이유**: 교습과정 공시가 '미술' 한 줄인 곳이 많아,
  상세도를 재면 학원의 차이가 아니라 **공시 습관**을 재게 된다.
- **진입난이도를 빼는 이유**: 레벨테스트·대기 개념이 없는 곳이 대부분이라
  신호가 안 잡힌다. **없는 것을 0점으로 치면 그게 곧 왜곡이다.**
- 그래서 두 기둥은 `0` 이 아니라 **`null`** 로 내보내고, 앱도 없는 기둥은
  아예 그리지 않는다.
- **과목별 랭킹만 둔다.** 수학 학원과 미술 학원을 한 줄에 세우면 그 순위가
  무엇을 뜻하는지 설명할 수 없다.

### 4.6 표본과 등수 — '안 본 것'과 '보고서 낮은 것'은 다르다

| 표본 | 순위 | 화면 표기 |
|---|---|---|
| 0건 | **매기지 않는다** | 등수 없이 '근거 없음' · 점수도 '—' |
| 1–9건 | 매긴다 | '표본 부족 · N건' 을 함께 적는다 |
| 10–29건 | 매긴다 | `표본 보통` |
| 30건+ | 매긴다 | `표본 충분` |

- **표본 0 은 '적다'가 아니라 '없다'.** 점수가 코호트 평균(50)으로
  채워지므로 등수를 붙이면 그건 평가가 아니라 기본값이다. 상세 화면의
  점수·다이얼도 함께 감춘다.
- **표본 1–9 는 예전엔 통째로 뺐다.** 그랬더니 96개 조합(4학군 × 6과목 ×
  4구간) 중 순위가 10곳을 넘는 곳이 **하나뿐**이었다 — '반포 과학 초등'을
  누르면 빈 화면이었다. 등수를 감추는 대신 **근거의 두께를 함께** 보여
  주는 쪽으로 바꿨다. 다만 목록에서는 표본 10건 이상을 먼저 세운다 —
  표본 1건이 표본 130건 위에 서면 그 등수가 무엇을 뜻하는지 설명할 수 없다.
- **미수집 학원에는 점수를 붙이지 않는다.** 등록부(`registry.json`)와
  채점 대상(`academies.json`)을 나눈 이유다.

### 4.7 점수는 (학원 × 과목) 마다 따로 낸다
한 학원에 점수 하나만 두면, 수학 후기 496건짜리 종합학원이 그 점수를
그대로 들고 과학 랭킹 3위에 오른다. 그 순위는 '이 학원의 과학이 좋다'가
아니라 '이 학원이 유명하다'를 뜻하게 된다.

- 과목이 하나인 학원: 모든 글이 그 과목 근거.
- 여러 과목인 학원: **글이 그 과목을 명시해야** 근거로 친다. 과목 불명
  글은 **대표 과목에만** 넣는다.
- 코호트·표본 부족 판정·등수까지 전부 과목별.
- 과목을 특정할 수 없는 곳(종합·보습·재종)은 `general` 로 두고 **어느
  과목 랭킹에도 넣지 않는다.** 어느 과목으로 견줄지 정할 수 없으면
  등수도 매길 수 없다. 등록부에는 남는다.

**학급(학년 구간)별 점수는 아직 내지 않는다.** 실측(24,369건)에서 학급
신호가 있는 글이 7%뿐이라, (학원 × 과목 × 학급) 862개 엔티티에 평균 한
건이 안 된다. 학급은 학원 단위로만 정하고 점수는 과목 단위로 낸다.

### 4.8 실효 기여 — 가중치와 영향력이 어긋나면 안 된다

가중치가 같아도 **분산이 다르면 영향이 다르다.**

```
실효 기여 = 가중치 × 그 기둥의 표준편차
```

기둥을 추가하거나 가중치를 바꾸면 **반드시 다시 재야 한다.** 명목
가중치 순서와 실효 기여 순서가 어긋나면 산식을 공개하는 의미가 없다 —
'평판 35%'라고 적어 놓고 실제로는 화제성이 순위를 가르는 상태가 된다.
파이프라인이 매 실행 이 값을 찍고, 순서가 어긋나면 경고한다.

## 5. 데이터 파이프라인

```
[NEIS 학원교습소정보 API]  ──┐
   공식 · 검증 · 매일          │
                              ├─→ normalize → match → score → Supabase → Flutter(web/iOS/Android)
[네이버 검색 API]           ──┤     (학원명 정규화 + 주소 지오코딩으로 엔티티 매칭)
   카페글/블로그/지식iN        │
                              │
[카페 수집 모듈 (로컬 전용)] ──┘
   opt-in · 서비스 비의존
```

### 소스별 역할과 위험도

| 소스 | 역할 | 법적 지위 | 서비스 의존도 |
|---|---|---|---|
| NEIS `acaInsTiInfo` | 학원 원장(原帳). 이름·주소·정원·교습비·등록상태 | 공공데이터, 자유 이용 | **필수** |
| 네이버 검색 API | 평판/화제성 신호 (스니펫 단위) | 공식 API, 약관 준수 | **필수** |
| 카페 직접 수집 | 심층 후기 텍스트 | **네이버 약관 위반 소지** | **선택 — 없어도 서비스 완전 동작** |

> **설계 원칙:** 카페 수집 모듈은 로컬에서만 실행되고, 산출물은 집계 신호로만 반영된다.
> 원문은 저장·재배포하지 않으며, 서비스는 이 모듈이 없어도 전 기능이 동작한다.

## 6. 법적 · 윤리적 방어선

실명 사업자를 점수화해 공개하는 서비스다. 한국에서는 **사실적시 명예훼손**이 성립하므로, 다음을 제품에 내장한다.

1. **산식 전면 공개** — 각 학원 상세에 기둥별 점수와 계산 근거를 노출.
2. **근거 원문 링크** — 평판 점수에 반영된 게시물의 원문 링크를 제공(본문 전재 금지, 링크+최소 인용).
3. **의견/사실 분리** — 공식 데이터는 `검증됨`, 커뮤니티 파생은 `추정` 배지로 시각적 분리.
4. **정정 요청 창구** — 학원 운영자용 이의제기 폼. 접수 시 해당 점수에 `검토 중` 배지, 7일 내 처리.
5. **표본 부족 학원 순위 제외** — 소수 악성 후기로 하위권이 만들어지지 않도록.
6. **이해상충 고지** — 운영사 Open Edu는 영어 교육 사업자. 관련 항목에 고지 배너.
7. **개인정보 미수집** — 게시물 작성자 ID는 해시 후 저장(중복 판별용), 원문 ID 미저장.
