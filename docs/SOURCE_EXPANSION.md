## 화면과 데이터 계약

- 학습 방향·입학 정보에는 `shortSummary`만 표시하고 출처 버튼으로 전체 짧은 요약과 원문을 연다.
- `subjects`가 맞는 항목만 해당 과목 카드에 노출한다. `sourceScope: brand`는 화면에서도
  `브랜드 공통 안내`로 표시하며 지점별 반·일정으로 단정하지 않는다.
- 기존 3개 학원의 원문과 확인일은 보존했다. 짧은 문구는 기존 검증 요약을 축약했다.
- 공식 안내는 학원 자기 서술이다. 만족도·진입 난이도·아이 적합성으로 추론하지 않으며,
  후기 표본 수와 랭킹 점수에 합산하지 않는다.
- `source_notes_test.dart`에서 ID·URL·날짜·과목/범위, 과목 혼입 방지와 모바일 원문 패널을 검증한다.
